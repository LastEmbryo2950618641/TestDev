# 组织与势力

本文件从人物、职业身份、地点和关系索引中抽取默认常驻的组织/势力入口。具体关系和阶段变化以关系卡为准。

- 攻略组玩家：挑战前线楼层Boss的高风险玩家。。
- 锻造师：制作和强化装备的玩家。。
- 桐人 / 亚丝娜：搭档/恋人，两人在死亡游戏中从前线搭档发展为互相支撑的亲密关系。
- 桐人 / 茅场晶彦：玩家/规则制定者，桐人面对的是茅场创造的世界与伦理代价。
- 桐人 / 克莱因：初始友人/战友，克莱因让桐人早期并非完全孤立，也代表桐人未能照顾所有人的遗憾。
- 桐人 / 艾基尔：前线同伴/后勤支点，艾基尔用商人资源和战士身份支撑桐人与攻略组。
- 桐人 / 幸：隐瞒者/负罪感，幸与月夜黑猫团事件成为桐人独行和自责的重要心理节点。
- 桐人 / 莉兹贝特：委托对象/短暂心动，莉兹贝特通过锻造委托靠近桐人，也看见桐人与亚丝娜的关系。
- 桐人 / 西莉卡：救助者/前辈，桐人救助西莉卡并帮助她面对欺骗和失去。
- 桐人 / 结衣：父女式家人，结衣把桐人与亚丝娜的关系转化为可加载的家庭结构。
- 亚丝娜 / 结衣：母女式家人，亚丝娜与结衣的亲密让虚拟世界中的家具有真实重量。
- 亚丝娜 / 优纪：朋友/生命理解，优纪让亚丝娜重新理解虚拟世界中的相遇和生命痕迹。
- 桐人 / 诗乃：战友/创伤共鸣，桐人与诗乃共同面对死枪事件，彼此看见现实创伤。
- 诗乃 / 死枪：受害威胁/创伤触发，死枪利用枪与死亡象征触发诗乃的现实创伤。
