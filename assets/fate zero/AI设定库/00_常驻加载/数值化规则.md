# 数值化规则

## 主数值
所有AI推演属性采用0-100。0代表无，100代表当前作品内规格外顶点。除FGO/原作明确给出等级外，均标注为“AI推演值”。

| 数值 | 等级 | 含义 |
|---:|---|---|
| 0 | 无 | 不具备该属性 |
| 1-20 | 极低 | 普通人以下或几乎不可用 |
| 21-40 | 低 | 低于常规魔术师或低规格战斗单位 |
| 41-60 | 中 | 标准人类/普通魔术师/低阶从者表现 |
| 61-80 | 高 | 优秀魔术师或强力从者表现 |
| 81-95 | 极高 | 顶级、名门、强英灵或强宝具规格 |
| 96-100 | 规格外 | 破格、异常、系统例外 |

## Fate参数映射
| 官方等级 | AI建议值 | 说明 |
|---|---:|---|
| E | 20 | 从者参数最低档 |
| D | 35 | 偏低 |
| C | 50 | 标准 |
| B | 65 | 优秀 |
| A | 80 | 顶级 |
| A+ | 88 | 条件爆发或瞬间强化 |
| A++ | 94 | 极高规格 |
| EX | 95 | 规则外，需单独解释，不等于永远最强 |

## 可信度
- 高：正文直接明确，或FGO Wiki明确参数。
- 中：正文多处表现支持，但没有官方数值。
- 低：为AI推演补全，需谨慎使用。

## 使用限制
战斗推演不得只比较数值。必须同时考虑情报、先手、Master供魔、地形、宝具相性、令咒、心理状态、剧情限制、是否隐蔽行动。
