# 组织与势力

本文件从人物、职业身份、地点和关系索引中抽取默认常驻的组织/势力入口。具体关系和阶段变化以关系卡为准。

- Master：被圣杯选中并持有令咒的人类参战者，负责召唤、供魔和指挥从者。。
- Servant：英灵通过职阶容器现界后的战斗单位。。
- Saber：剑士职阶，高规格近战、对魔力和骑乘适性。。
- Archer：弓兵职阶，在本作表现为宝具库存、远程压制与单独行动。。
- Lancer：枪兵职阶，高速近战与对单体压制。。
- Rider：骑兵职阶，机动、骑乘、战车与军势宝具适性。。
- Caster：术师职阶，阵地建造、召唤与工房型威胁。。
- Assassin：暗杀者职阶，气息遮断、侦察、潜伏和分布式情报。。
- Berserker：狂战士职阶，狂化提升性能但破坏理性并加重供魔负担。。
- 魔术师：以魔术回路、刻印、家系和神秘研究为核心的隐秘阶层。。
- 圣堂教会代行者：教会执行异端处理与神秘干预的人类战斗者。。
- 监督役：以中立名义管理战争、回收令咒、隐蔽神秘的教会职位。。
- 卫宫切嗣 / 爱丽丝菲尔·冯·爱因兹贝伦：夫妻/共犯式理想，爱丽丝菲尔理解并支撑切嗣的理想，同时也是小圣杯牺牲者。
- 卫宫切嗣 / Saber_阿尔托莉雅·潘德拉贡：御主与从者/价值观冲突，契约成立但战术与伦理完全不合，切嗣依靠爱丽丝菲尔代理沟通。
- 言峰绮礼 / 远坂时臣：弟子/协力者/背叛伏线，表面协助远坂，内里因自我空洞与吉尔伽美什诱导逐渐偏离。
- 言峰绮礼 / 卫宫切嗣：宿敌/镜像，二人都以极端方式处理欲望与救赎，是本作价值观核心对照。
- 韦伯·维尔维特 / Rider_伊斯坎达尔：御主与从者/成长关系，Rider重塑韦伯对王、器量与自我价值的理解。
- 肯尼斯·埃尔梅罗·阿奇博尔德 / Lancer_迪尔姆德·奥迪那：御主与从者/信任崩坏，Lancer忠诚但受肯尼斯、索拉乌和切嗣战术共同压迫。
- 间桐雁夜 / 间桐樱：保护者/被保护者，雁夜参战的主要动机是救樱脱离间桐家。
- 远坂时臣 / 远坂凛/间桐樱：父女/家系选择，时臣以魔术师家系逻辑安排女儿命运，引发后续悲剧。
- Saber_阿尔托莉雅·潘德拉贡 / Lancer_迪尔姆德·奥迪那：骑士对手，二者在战斗礼仪上互相承认，但被御主战术撕裂。
- Saber_阿尔托莉雅·潘德拉贡 / Berserker_兰斯洛特：旧主与圆桌骑士/罪责，兰斯洛特的狂化执念直指亚瑟王传说中的旧伤。
- 言峰绮礼 / Archer_吉尔伽美什：诱导者与被诱导者，吉尔伽美什促使绮礼正视自身愉悦与欲望。
- 雨生龙之介 / Caster_吉尔斯·德·莱斯：御主与从者/共犯，二者不以圣杯为核心，而以杀戮和异常审美制造灾害。
