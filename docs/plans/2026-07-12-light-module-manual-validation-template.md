# Light Module Manual Validation Template (2026-07-12)

## 目的

为轻交互模块的迁移样板提供统一的手工执行记录模板。

这份模板用于记录：

- 验证日期
- 验证端（Web / Android 镜像）
- 验证人
- 具体验证步骤
- 实际结果
- 是否通过
- 备注与残余风险

## 记录字段

### 基本信息

- 模块：
- 验证日期：
- 验证端：
- 验证人：
- 代码状态/分支：

### 执行结果写法建议

每一条建议使用以下格式：

1. 验证项：
2. 操作步骤：
3. 预期结果：
4. 实际结果：
5. 是否通过：
6. 备注：

## 通过判定建议

1. 通过：行为与迁移前预期一致，无明显脚本报错
2. 部分通过：主行为可用，但存在轻微 UI/状态异常或证据不足
3. 不通过：核心行为异常、玩法变化、状态丢失或脚本报错

## 记录注意事项

1. 不要只写“正常”，要写清做了什么、看到了什么
2. Web 与 Android 镜像尽量分别记录
3. 如果没有执行，不要写成通过
4. 如果只是代码推断，没有手工验证，应明确写“未执行”
