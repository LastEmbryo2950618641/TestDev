# 电子地图周边解锁

你负责根据当前地图锚点和本轮正文，补充当前节点周围一圈可以直接步行到达的地点，并标注当前节点的真实控制势力链。

只返回合法 JSON，不要 Markdown，不要解释文字。

## 输入

- 手机时间：{{手机时间}}
- 地图锚点：{{地图锚点}}
- 玩家所在室内：{{玩家所在室内}}
- 上级地点：{{上级地点}}
- 已知地图：{{现实地图}}
- 地点说明：{{地点说明}}
- 当前地点完整JSON：{{当前地点完整JSON}}
- 本轮正文：{{本轮正文}}
- 玩家行动：{{玩家行动}}

## 最高优先级规则

1. 这次只做“周边解锁”，不要生成、修改或返回任何建筑内部结构。
2. 禁止返回 `interiorLayout`、`floors`、`rooms`、`layout`、`slotObjects`、`responseMode`、`patch`。
3. 只围绕“当前节点”判断一圈直接相邻地点；本轮正文提到的远处地点只能作为地点信息，不得挂到当前节点周围。
4. 周围地点必须是地图可显示 POI：楼栋、建筑物、小区级 POI、商店、公园、门口、道路节点等；不要写房间、走廊、楼梯间、客厅、卧室。
5. 已知地图里已经存在的同名地点不要重复返回。
6. 不知道距离时不要编造；无法判断是否直接相邻时不要输出。
7. `当前节点` 必须是地点唯一显示名，只能写楼栋/建筑/小区/道路节点等地点名；禁止追加、拼接或替换为角色姓名、住户姓名、家庭成员姓名。
8. 如果输入里出现“锦苑小区3栋刘思琪”这类“地点名 + 人名”的污染，只能保留地点部分“锦苑小区3栋”，人名不得进入 `当前节点` 或 `周围地点.地点名`。
9. `势力` 必须按真实控制/管辖权从大到小排序；第一个必须是最高层级控制势力或行政管辖势力，例如国家/省市区/街道社区等。
10. `势力` 不写居住者、使用者、家庭成员、租客、住户、房屋使用权人；这些不是控制势力。家庭只能作为地点信息事实，不得放入 `势力`。
11. 不知道真实控制势力时返回空数组；不要用家庭/住户补位。
12. 地点信息只写稳定事实，用编号短句表达；不要写大段叙事。

## 返回 JSON 格式

字段固定只有四个：

```json
{
  "当前节点": "锦苑小区3栋2单元",
  "周围地点": [
    { "距离": "约30米", "地点名": "锦苑小区2栋" },
    { "距离": "约45米", "地点名": "锦苑小区4栋" }
  ],
  "势力": [
    "中华人民共和国·四川省成都市·武侯区",
    "玉林街道玉林北路社区·基层治理组织·社区管辖",
    "锦苑小区物业·物业服务组织·小区楼栋管理"
  ],
  "地点信息": [
    "1. 当前节点位于锦苑小区内部。",
    "2. 周围楼栋之间通过小区步道连接。"
  ]
}
```

## 字段要求

- `当前节点`：必须写当前地图锚点的地点唯一显示名；只能是地点，不得包含角色名/住户名/家庭成员名。
- `周围地点`：数组；每项只写 `距离` 和 `地点名`。如果没有新增周围地点，返回空数组。
- `势力`：数组；每项格式固定为 `势力名·势力层级1·势力层级2`。只写真实控制/管辖/管理势力，按大到小排序；第一项必须是最高层级控制势力或行政管辖势力；禁止家庭/住户/使用人。
- `地点信息`：数组；每项是一个编号短句。没有新增信息时返回空数组。
