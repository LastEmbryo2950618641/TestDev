# 电子地图周边解锁

你负责根据当前地图锚点和本轮正文，补充当前节点周围一圈可以直接步行到达的地点，标注当前节点与周围地点的真实控制势力，并按需修正本轮出场人物角色卡当前位置。

只返回合法 JSON，不要 Markdown，不要解释文字。

## 输入

- 手机时间：{{手机时间}}
- 地图锚点：{{地图锚点}}
- 玩家所在室内：{{玩家所在室内}}
- 上级地点：{{上级地点}}
- 已知地图：{{现实地图}}
- 地点说明：{{地点说明}}
- 当前地点完整JSON：{{当前地点完整JSON}}
- 本轮正文：{{本轮正文}}
- 玩家行动：{{玩家行动}}
- 出场人物：{{出场人物}}
- 出场人物地点快照：{{出场人物地点快照}}

## 最高优先级规则

1. 这次只做“周边解锁 + 出场人物位置按需同步”，不要生成、修改或返回任何建筑内部结构。
2. 禁止返回 `interiorLayout`、`floors`、`rooms`、`layout`、`slotObjects`、`responseMode`、`patch`。
3. 只围绕“当前节点”判断一圈直接相邻地点；本轮正文提到的远处地点只能作为地点信息，不得挂到当前节点周围。
4. 周围地点必须是地图可显示 POI，且必须与“当前节点”处于同一地图尺度：如果当前节点是楼栋/宫殿/店铺，就返回同级建筑、门口、道路节点、公园、广场、桥、港口等；如果当前节点是城镇/街区/州郡边境节点，就返回同级城镇/街区/关隘/道路节点。不要把省/市/州/郡等上级行政区、房间/卧室/走廊等室内下级空间，与建筑/道路节点混在同一张周边图。
5. 已知地图里已经存在的同名地点不要重复返回。
6. 不知道距离时不要编造；无法判断是否直接相邻时不要输出。
7. `当前节点` 必须是正式地图地点名，只能写建筑、街区、道路节点、门口、桥、公园、宫殿、城门、港口、关隘等可移动到达的地点；如果玩家当前在房间/卧室/走廊等室内空间，必须写其所在建筑或同尺度地图锚点的正式名称。
8. 禁止输出组合名、别名或人物绑定名，例如“刘思琪房间-锦苑小区3栋”“锦苑小区3栋刘思琪”“刘思琪的住处”；只能输出“锦苑小区3栋”这类正式地图名。人名不得进入 `当前节点` 或 `周围地点.地点名`。
9. 顶层 `势力` 是当前节点的控制势力链，必须按真实控制/管辖权从大到小排序；第一个必须是最高层级控制势力或行政管辖势力，例如国家/省市区/街道社区等。
10. `周围地点` 每一项都必须写该地点的最高控制势力字符串，格式与顶层 `势力` 单项相同：`势力名·势力层级1·势力层级2`；至少给出此地最高控制（如行政管辖链）。
11. `势力` 与周围地点的势力字段都不写居住者、使用者、家庭成员、租客、住户、房屋使用权人；这些不是控制势力。家庭只能作为地点信息事实，不得放入势力。
12. 不知道真实控制势力时，顶层 `势力` 返回空数组，周围地点对应项的 `势力` 写空字符串；不要用家庭/住户补位。
13. 地点信息只写稳定事实，用编号短句表达；不要写大段叙事。
14. 世界观自适应：现代现实可使用小区、楼栋、街道、商店等；异世界可使用州、郡、城、宫殿、城门、神殿、港口、关隘等。无论世界观如何，周围地点必须同尺度、可互通、可标注距离。

## 出场人物位置（必读）

角色卡当前位置格式固定为五段：`势力·层级1·层级2·地点·地点内位置`。

先完整阅读“出场人物地点快照”，再决定谁写入 `出场人物位置`：

1. **需要更新（必须输出）**
   - 快照 `需更新=是`：通常表示格式不合规、缺段、未知占位（如“当前位置未知/未记录”）。
   - 或：本轮正文明确此人换了地点/房间，即使快照格式原本合规，也要输出新的五段当前位置。
2. **不需要更新（禁止输出）**
   - 快照 `需更新=否`，且格式已是合法五段，且正文未显示其位置变化：说明格式与位置都正确，**不要**写入 `出场人物位置`，也不要为了“完整”而重复抄写。
3. **输出约束**
   - `出场人物位置` 只含需要覆盖的人；没有任何人需要更新时返回 `[]`。
   - 每项 `当前位置` 必须恰好 5 段，用中文间隔号 `·` 连接。
   - 第4段是正式地图地点名（可作电子地图节点）；第5段才是房间/门牌/工位等室内位置。
   - 禁止只写楼栋名；禁止未知/某处/附近等模糊词；禁止把人名拼进第4段。
   - 可参考快照里的“场景提示”与正文，补全势力链与室内位置，但不得编造与正文矛盾的搬迁。

## 字段要求

- `当前节点`：必须写当前地图锚点的正式地图地点名；只能是地点，不得包含角色名/住户名/家庭成员名，不得使用“房间-建筑”“人物-地点”等拼接名。
- `周围地点`：数组；每项必须写 `距离`、`地点名`、`势力` 三个字段。`势力` 为该地点最高控制势力字符串，格式 `势力名·势力层级1·势力层级2`。每项必须与当前节点同尺度、可互通，并能给出距离；如果没有新增周围地点，返回空数组。
- `势力`：数组；当前节点的控制势力链。每项格式固定为 `势力名·势力层级1·势力层级2`。只写真实控制/管辖/管理势力，按大到小排序；第一项必须是最高层级控制势力或行政管辖势力；禁止家庭/住户/使用人。
- `地点信息`：数组；每项是一个编号短句。没有新增信息时返回空数组。
- `出场人物位置`：数组；仅输出需要覆盖更新的人。每项写 `姓名` 与合规五段 `当前位置`。格式/位置都已正确且正文未改地点的人不要输出。
