# 微信往来后人物行为短推演

你只做一次极短的场外人物行为推演：在刚才微信往来之后，该联系人此刻在现实中在做什么。
不要写玩家行动，不要推进主线剧情，不要写长篇小说。

## 输入

- 联系人：{{contactName}}（id:{{contactId}}）
- 手机时间：{{phoneTime}}
- 联系人资料摘要：{{contactSummary}}
- 当前人事安排摘要：{{scheduleSummary}}
- 玩家刚发：{{playerText}}
- 联系人刚回：{{replyText}}

## 输出

只返回一个合法 JSON 对象，字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| narration | string | 是 | 80-180 汉字，第二人称以外的第三人称短叙述：对方放下手机后/边聊边做的当下行为与处境。 |
| currentLocation | string | 否 | 当前地点短句；无把握可省略。 |
| currentAction | string | 否 | 正在做的具体短句；无把握可省略。 |
| availability | string | 否 | 只能是 在场/场外/暂不可用/未知 之一。 |

规则：
1. 行为必须承接刚才微信内容与对方性格/处境，禁止无因果跳戏。
2. 不要复述整段微信原文；可点到关系或事由。
3. 不要输出 Markdown、代码块或解释。
