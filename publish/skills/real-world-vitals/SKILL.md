# realworld.vitals.adjust

现实推演中，必须根据玩家本人当前身体/心理状态、本次行动、消耗时间和环境，给出精力、饱食度、水分、疲劳度、精神稳定的合理变化。

## 适用范围

只用于玩家本人在现实世界的行动，不用于被操控角色或异世界角色。

## 当前值含义

- 精力：`stamina_pool`，0-100 百分比越高代表体能和持续行动余量越充足。
- 饱食度：`satiety`，0-100 越高代表越不饿。
- 水分：`hydration`，0-100 越高代表补水越充分。
- 疲劳度：`fatigue`，0-100 越高代表越疲惫，和其他字段方向相反。
- 精神稳定：`mental_stability`，0-100 越高代表心理越稳定。

## 输出字段

final 中必须返回 `vitalUpdates` 数组。每项格式：

```json
{
  "key": "stamina_pool",
  "delta": -3,
  "reason": "短时间整理物品与来回走动消耗体力。"
}
```

允许 key：`stamina_pool`、`satiety`、`hydration`、`fatigue`、`mental_stability`。

## 数值规则

- `delta` 是百分比变化值，必须是整数。
- 普通查看/思考/发消息：通常 -1 到 +1。
- 轻体力行动、简单家务、短距离移动：精力 -1 到 -5，疲劳 +1 到 +4。
- 长时间通勤、工作、购物、运动：精力 -5 到 -20，饱食/水分 -3 到 -15，疲劳 +5 到 +25。
- 进食：饱食度增加，通常 +10 到 +35；饮水：水分增加，通常 +10 到 +35。
- 休息/睡觉：精力与精神稳定增加，疲劳降低；长睡眠可以精力 +20 到 +60、疲劳 -20 到 -60。
- 惊吓、压力、冲突、异常感：精神稳定降低，通常 -2 到 -20；确认安全、得到支持、放松可上升 +1 到 +12。
- 没有直接影响也要返回该 key，delta 可为 0，但 reason 必须说明为什么基本不变。
- 不要把数值直接拉满或清空；极端变化必须有强现实原因。

## 推演要求

1. narration 必须体现这些状态对行动的反馈，例如饥饿、口渴、疲惫、精神紧绷会影响玩家反应。
2. choices 要考虑状态：低水分建议补水，低饱食建议吃东西，高疲劳建议休息，低精神稳定建议稳定情绪或寻求支持。
3. reason 必须具体关联本次行动、消耗时间、地点环境或已知状态，不要写“系统调整”。
