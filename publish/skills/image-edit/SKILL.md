# 图片编辑调用 Skill

## 激活描述

当微信联系人在对话中判断可以或应该发送自拍照时，不要立即生成图片。先返回发送图片意图，由界面展示空白图片按钮。只有玩家点击接受并确认“是否确认接受（会生成图片）”后，才调用图片编辑。

## 调用规则

1. 图片编辑必须以玩家标记的角色真实照片为基础图。
2. 调用前先收集本次图片所需动态标签，再把动态标签填入通用图片编辑与生成提示词。
3. 编辑目标是保持同一角色，按标签调整穿戴、表情、姿势、氛围、场景和光影。
4. 不要在普通微信回复阶段触发图片生成；普通回复只表达“愿意发送/可以发一张”的意图。
5. 若没有角色真实照片，不能调用编辑，需提示玩家先在相册标记真实照片。

## 输出要求

图片编辑结果应作为微信图片消息显示给玩家，保留 taskId 以便后续下载或跳转。
