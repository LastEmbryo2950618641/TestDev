# Taobao Domain Helpers

该目录用于承载淘宝模块中与平台、DOM、AI 请求主流程无关的只读规则、标准化逻辑与购买外围 helper。

当前已覆盖：

- 筛选与部位匹配规则
- 搜索批次与目标槽位派生
- 商品标准化
- 购买前目标解析
- 购买前轻规则判断
- 购买结果文案与库存更新规则

当前不放：

- 生成请求主循环
- 购买副作用主链
- 持久化时机
- 资产同步执行

说明：虽然当前文件名仍为 `filter-helpers.js`，但它实际上已经承载了淘宝模块的第一批 domain 样板能力。后续若继续扩展过大，再考虑按 `filter` / `product-normalization` / `buy-rules` 进一步拆文件；在没有明确收益前，优先保持现有加载链稳定。
