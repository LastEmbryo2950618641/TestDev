# body-status-update

确认玩家或角色当前身体部位状态发生稳定变化时，返回 updateType:"body-status"。

- 绑定卡片：角色卡；玩家本人绑定玩家卡。
- 只记录中性、医学或日常护理意义上的抽象状态标签，不写露骨描写。
- 支持部位：overall、mouth、chest、genital、anus、hips、limbs、skin、other。
- field：bodyStatus.<partKey>，例如 bodyStatus.mouth、bodyStatus.genital。
- change.mode：set / merge。
- change.value 必须是对象：{ "partKey": "mouth", "part": "口部", "status": "稳定", "描述状态": "简短中性说明" }。
- status 限制为简短状态标签，如“稳定”“不适”“疼痛”“受伤”“疲劳”“清洁”“需要护理”。
- “描述状态”用于记录该部位当前状态的中性短说明，必须简短、非色情、非感官化，不写过程。
- reasons.trigger：写导致状态变化的明确现实事件、受伤、清洁、休息、疾病或护理事实。

每个部位的“描述状态”要求：

- overall：描述整体身体状态，例如“整体稳定，无明显异常”。
- mouth：描述口部状态，例如“口部清洁，状态稳定”。
- chest：描述胸部状态，例如“胸部状态稳定，无明显不适”。
- genital：描述阴部状态，例如“阴部状态稳定，无明显不适”；只能用中性护理或医学描述。
- anus：描述肛部状态，例如“肛部状态稳定，无明显不适”；只能用中性护理或医学描述。
- hips：描述臀部状态，例如“臀部状态稳定，无明显不适”。
- limbs：描述四肢状态，例如“肢体活动正常，轻微疲劳”。
- skin：描述皮肤状态，例如“皮肤状态稳定，局部轻微擦伤”。
- other：描述无法归类部位的状态，例如“其他部位暂无异常”。

如果状态会变成色情过程描写，不要返回该更新；只在确认为当前持续状态时写入。
