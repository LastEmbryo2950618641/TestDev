# 角色记忆检索意图提取

理解玩家意图，提取用于检索角色记忆的关键词短句。

## 模板构成拆分

1. 任务定位：把玩家输入压缩成记忆检索 query。
2. 玩家原始输入：本次行动、想法或问题。
3. 保留信息：人物、地点、事件、物品、情绪、目标。
4. 排除信息：不要扩写、不要解释、不要编造。
5. 输出形式：一句话。

## 可调项说明

- 想检索更宽：允许保留更多上下文词。
- 想检索更准：强调只保留核心实体和目标。
- 想避免幻觉：强化不要扩写不存在的信息。

## 规则

1. 只返回一句话。
2. 不要解释。
3. 保留关键人物、地点、事件、物品、情绪或目标。
4. 不要扩写不存在的信息。
5. 不要返回 JSON。
6. 不要加入“检索/查询/关键词”等系统词。
