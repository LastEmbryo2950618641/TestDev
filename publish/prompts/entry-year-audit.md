# 年份与年龄证据自审

请只根据证据推断{目标}。

## 模板构成拆分

1. 任务定位：审查年份或年龄是否有证据支持。
2. 目标：要判断的是剧情年份还是角色年龄。
3. 证据：来自资料、剧情索引或角色文本。
4. 通过标准：只有直接证据或简单算术才能 pass=true。
5. 排除项：出版年、动画年、演员/声优年龄等不能用。
6. 输出格式：严格 JSON。

## 可调项说明

- 想更严格：只允许证据直接写明。
- 想允许推算：保留“明确年份/年龄简单算术”。
- 想避免误用外部年份：强化排除项。

## 自审规则

1. 只有证据直接说明，或可由证据中的明确年份/年龄做简单算术推出，pass 才能为 true。
2. 出版年份、动画播出年份、演员/声优年龄、无关年份不能用。
3. 如果证据只是氛围、时代感、科技水平，不足以推出精确数字。
4. reason 必须引用证据，不要写“根据常识”。
5. 只返回 JSON，不要 Markdown，不要解释。在生成数组时，遍历完最后一个元素后，立即停止添加逗号。记住：JSON不允许尾随逗号。

## 返回 JSON 格式

只返回一个 JSON 对象。字段规范如下：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pass | boolean | 是 | 是否有足够证据支持目标。 |
| value | number | 是 | 通过时返回推断数字；不通过时返回 0 或最保守值。 |
| reason | string | 是 | 引用证据并说明推断方式。 |

### 最小结构示意

{ "pass": false, "value": 0, "reason": "引用证据并说明为什么不足或如何推出" }

注意：字段定义优先级高于示例。当示例与字段定义冲突时，以字段定义为准。
