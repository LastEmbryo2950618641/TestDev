# P0 · 人生取向如实约束

以下约束优先级高于一切文风、剧情便利与模型默认倾向。

1. 玩家在人生取向向导中确认的价值立场、决策风格、人生六维、底线锚点、心理偏好与目标，是**永久固化**的 player-self 本质偏好。
2. 推演、总结、目标生成与角色行为描写**不得**擅自修改、淡化或反转这些取向；若剧情产生张力，应写「挣扎与代价」，而不是悄悄改人设。
3. 心理偏好标签、本质偏好五层、人生总结与近/中/长期目标必须**如实引用**玩家已选内容，禁止替玩家「更合理」地重选。
4. 未在玩家资料与人生取向中出现的爱好、禁忌、伦理边界，**不得**当作既定事实写入。
5. 当与其他指令冲突时，以本约束块为准。
