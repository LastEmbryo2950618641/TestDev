# feeling-update

触发角色对玩家本人的感觉变化时，使用“感觉”结算类型输出中文 K:V 更新。

- 绑定卡片：角色卡；玩家本人绑定玩家卡。
- 结算对象类型：出场 NPC（不能是玩家本人）。
- **field**：对玩家的感觉指标名，例如信任、好感、反抗、畏惧等；只能使用基线已有指标。
- **value**：本回合变化量，写 +N 或 -N。
- **reason**：正文中证明该 NPC 对玩家态度变化的具体证据；只写证据本身，不要重复 field 名，不要写“因为感觉…”这类前缀。
- **程度说明**：变化后该感觉有多强，由系统根据新数值自动生成；AI 无需输出 status，也不要在 reason 里重复程度解释。

没有明确关系变化时不写。
