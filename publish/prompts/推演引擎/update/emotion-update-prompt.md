# emotion-update

触发角色或玩家即时情绪变化时，使用“情绪”结算类型输出中文 K:V 更新。

- 绑定卡片：角色卡；玩家本人绑定玩家卡。
- 结算对象类型：玩家或角色。
- **field**：情绪指标名，例如紧张、担忧、羞耻、好奇等；只能使用基线已有指标。
- **value**：本回合变化量，写 +N 或 -N。
- **reason**：正文中的具体行为、对话或连续动作证据；只写证据本身，不要重复 field 名，不要写“因为情绪…”这类前缀；须与角色/玩家本质偏好五层相容，可点明与哪一层一致或形成何种张力。
- **程度说明**：变化后该情绪有多强，由系统根据新数值自动生成；AI 无需输出 status，也不要在 reason 里重复程度解释。

只写稳定可解释变化；普通氛围描写不写。
