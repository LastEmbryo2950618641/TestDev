# Stage4 角色卡更新

确认玩家或角色卡资料、身份、职业、技能、外貌、性格、人际关系等稳定变化时，使用“角色卡”结算类型输出中文 K:V 更新。

- 绑定卡片：角色卡；玩家本人绑定玩家卡。
- 字段：身份、职业、技能、外貌、性格、人际关系、当前状态等中文字段。
- 操作：替换或增加。
- 只有稳定事实变化才写；临时情绪不要写入角色卡。
- **禁止修改本质偏好五层**：价值立场偏好、决策风格偏好、人生六维偏好、底线锚点偏好、心理偏好为永久固化字段，不得通过角色卡结算更新。

若变化能归入角色卡字段，优先使用角色卡类型。
