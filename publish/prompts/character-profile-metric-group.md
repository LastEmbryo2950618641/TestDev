# 角色卡初始数值组生成

只返回一个合法 JSON 对象，不要 Markdown、代码块或解释。

## 任务

为人物“{人物姓名}”生成初始{数值组名称}数值。

根字段必须是 `{根字段}`，值是数组。

数组必须按顺序完整返回这些 key：{字段列表}。

## 人物证据

{人物证据}

## 生成规则

1. 每一项都必须只有 `key`、`value`、`status`、`reason` 四个字段。
2. `value` 是 0-100 数字，由 AI 按当前人物性格、处境、经历、关系证据判断，不得照抄默认值。
3. `status` 写一句“该 key 为什么是该数值”的具体解释，要点名具体证据。
4. `reason` 写一句形成原因，结合角色动机、处境与过去经历。
5. 证据弱或没有触发时 `value` 可以为 0，但 `status/reason` 也必须说明缺少哪类证据。
6. 禁止写“默认、初始化、根据上下文、系统生成、综合判断、阶段定义、背景信息”等空话。
7. 不要返回英文 key、`initial_metrics`、`affection`、`dependency`、`trust_level` 等替代结构。

## 返回格式

```json
{"{根字段}":[{"key":"{首个字段}","value":0,"status":"具体解释","reason":"具体原因"}]}
```
