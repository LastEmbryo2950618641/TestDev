# 能力与升级体系设计

本文件是能力、等级、经验值与成长曲线的设计文档。它用于指导系统如何解释数值，不应整段塞入 AI 角色生成提示词。AI 提示词应优先引用 `ability-schema.md` 中的输出结构与规则。

## 设计目标

1. 等级能表达角色综合成长，但不能替代具体能力。
2. 基础能力体现当前生存状态，允许短期波动。
3. 身内能力体现底层资质，成长慢，不随单次事件随意变化。
4. 习得能力、技能、职业拥有独立等级与经验，能表现后天学习过程。
5. 非玩家角色没有机械刷怪升级公式，应根据剧情间隔、成长潜力、环境与经历推断成长。
6. 玩家角色可以使用明确经验公式，保证可玩性。

## 角色等级（1-100）

角色等级是综合评价，不等于战斗力。它综合考虑：身内能力、习得能力、职业成熟度、世界观强度、当前年龄与经历。

| 等级段 | 表现 |
| --- | --- |
| 1-9 | 普通人范围：幼童、弱者、普通成年人、训练有素的人类上限都在此范围内。 |
| 10-15 | 初入超凡：可单手破坏钢铁且无副作用，或轻松破坏水泥墙壁且无副作用。 |
| 16-19 | 稳定超凡：能压制现代武装个体，小范围破坏建筑结构。 |
| 20-24 | 街区级：单纯力量可压缩空气，破坏十几米长街道。 |
| 25-29 | 千人小镇级：单纯力量足以破坏约千人规模小镇。 |
| 30-34 | 万人小镇级：单纯力量足以破坏万人左右小镇。 |
| 35-39 | 十万人城镇级：可破坏十万人规模城镇。 |
| 40-44 | 百万人城市级：可破坏百万人规模城市。 |
| 45-49 | 千万人大都市级：可破坏千万人规模大都市。 |
| 50-59 | 国家级：可破坏法国、日本这类面积的国家。 |
| 60-69 | 大陆级到行星表层级。 |
| 70-79 | 行星级到恒星级。 |
| 80-89 | 星系级到宇宙级。 |
| 90-99 | 单体宇宙级到复数宇宙级。 |
| 100 | 多元宇宙级别。 |

## 经验值曲线

### 玩家角色经验曲线

玩家角色可使用明确升级公式：

```text
nextExp(level) = round(100 * level^1.65)
```

特点：

- 前期升级快，便于反馈。
- 中后期增长明显放缓。
- 允许通过任务、战斗、学习、训练、剧情突破获得经验。

### 非玩家角色成长方式

非玩家角色不使用固定刷经验公式，而使用成长推断：

```text
成长量 = 时间跨度 × 成长潜力 × 环境强度 × 实践频率 × 教育/训练质量 × 剧情压力修正
```

解释：

- 时间跨度：角色两次出场之间经过的时间。
- 成长潜力：0-100，越高越容易成长。
- 环境强度：日常环境低，战场/高压训练高。
- 实践频率：是否经常使用相关能力。
- 教育/训练质量：是否有导师、组织、资源、体系化训练。
- 剧情压力修正：重大创伤、觉醒、魔术改造等事件可改变成长。

非玩家再次出现时，AI 应给出“增长、停滞、退步”的解释，而不是直接套公式。

## 等级成长与自由属性点

角色获得个人经验并升级时，所有“与个人等级有关”的能力必须有明确成长算法，不能只增加等级数字。

### 升级结算顺序

```text
1. 扣除本级经验，个人等级 +1
2. 根据成长模板自动增加身内能力
3. 发放自由属性点
4. 重算生命力、精力、精神稳定、行动能力、攻防衍生
5. 写入升级记录
```

### 身内能力自动成长

每次个人等级提升时，系统根据角色身份、职业、技能和人物资料推导成长模板，并给身内能力加点：

```text
每级自动成长点 = 2 点
成长权重来源 = 角色职业/身份 + 已有技能 linkedStats + 当前身内能力短板
```

规则：

- 战斗、运动、士兵、骑士、武者：优先力量、敏捷、体质。
- 学生、学者、医生、魔术师、研究者：优先智力、感知、意志。
- 领袖、偶像、贵族、交涉型角色：优先魅力、意志、感知。
- 普通现代人或身份不明确：按当前短板轮流补齐，避免单项过高。
- 单项身内能力上限为 100；已满的属性跳过。

### 自由属性点

玩家角色或可被玩家长期培养的角色，每升 1 级获得自由属性点：

```text
每级自由属性点 = 1 点
可分配范围 = 力量、敏捷、体质、智力、感知、意志、魅力
```

自由属性点暂时不自动消费，写入 `free_attribute_points`，由后续 UI 或剧情奖励分配；非玩家角色也可保留该字段，表示可成长余量。初始等级不发放自由属性点，只有真实升级才发放。

### 身内能力来源展示

每个身内能力在 UI 展示时必须能展开查看来源：

```text
当前值 = 初始值 + 等级值 + 分配值 + 非玩家成长
```

- 初始值：角色首次入库时，根据资料和当前情况推演出的基础身内值；旧存档无来源时，当前值先归入初始值。
- 等级值：个人等级实际升级时由系统自动成长加上的值。
- 分配值：玩家消耗自由属性点手动分配得到的值。
- 非玩家成长：非玩家角色在时间流逝、训练、努力方向、剧情压力中自动分配得到的值。

### 派生属性重算

等级或身内能力变化后必须重算：

- 生命力最大值：等级、体质。
- 精力最大值：等级、体质、训练修正。
- 精神稳定最大值：意志。
- 行动能力最大值：敏捷、体质。
- 学习能力：智力为主，感知/意志辅助。
- 攻击力、防御力、战斗模拟。

## 基础能力数值曲线

基础能力多为当前值/最大值。最大值受身内能力、等级、年龄、种族、世界观强化影响；当前值受剧情即时状态影响。

### 生命力

生命力表示身体完整、生存状态与承伤余量。生命力是数值池，不是固定 0-100 百分比；最大值与等级和体质挂钩。

```text
生命力.max = round((等级 × 10) + (体质 × 8) + 种族/体型修正 + 特殊体质修正)
```

说明：

- 等级提供基础生命池，保证高等级角色不会被低级攻击轻易秒杀。
- 体质提供主要耐久差异，体质越高生命力上限越高。
- 种族/体型修正用于巨人、怪物、英灵、病弱幼童等特殊身体。
- 生命力数值必须和前文 0-100 表现力标尺平衡：超凡角色生命池可远高于普通人，但不能让同级攻击完全失效。

| 当前值比例 | 表现 |
| --- | --- |
| 100% | 状态完整。 |
| 75%-99% | 轻微擦伤或不影响行动。 |
| 50%-74% | 明显受伤，行动受影响。 |
| 25%-49% | 重伤，持续行动困难。 |
| 1%-24% | 濒死或几乎失去行动能力。 |
| 0% | 死亡、昏迷或剧情判定失去生存能力。 |

### 精力

精力表示体能和持续行动余量。精力也是数值池，最大值与等级和体质挂钩。

```text
精力.max = round((等级 × 8) + (体质 × 5) + 职业/训练修正 + 特殊体质修正)
```

说明：

- 等级越高，持续行动和连续释放能力越强。
- 体质越高，精力上限越高，恢复和耐疲劳更好。
- 职业/训练修正用于运动员、士兵、魔术师、病弱者等差异。
- 精力 current 会因行动、战斗、施法、奔跑、饥饿、缺水、疲劳而下降。

| 当前值比例 | 表现 |
| --- | --- |
| 80%-100% | 行动顺畅。 |
| 50%-79% | 正常消耗。 |
| 25%-49% | 疲惫，爆发力下降。 |
| 1%-24% | 极度疲惫，难以持续行动。 |
| 0% | 无法主动行动或需要立即休息。 |

### 饱食度 / 水分

饱食度和水分主要服务生存体验，不与等级直接挂钩。

- 饱食度低会影响精力恢复、精神稳定与行动能力。
- 水分低会快速影响生命力、精力与判断。
- 职业和环境会影响消耗速度，例如士兵、矿工、运动员、荒野旅行者消耗更快。

### 疲劳度

疲劳度是负面累积值，越高越糟。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 清醒。 |
| 21-40 | 略有疲倦。 |
| 41-60 | 明显疲劳。 |
| 61-80 | 判断下降、行动迟缓。 |
| 81-100 | 接近崩溃，可能昏睡或失误。 |

### 学习能力

学习能力影响习得能力经验获取效率。

```text
学习经验倍率 = 0.5 + 学习能力 / 100
```

例：

- 学习能力 20：0.7 倍。
- 学习能力 50：1.0 倍。
- 学习能力 90：1.4 倍。

### 精神稳定

精神稳定有当前值和最大值。当前值短期波动，最大值代表心理韧性上限。

- 受恐惧、操控、创伤、压力、精神攻击影响下降。
- 受休息、安抚、熟悉环境、信任关系影响恢复。
- 意志高的人精神稳定最大值通常更高。

### 成长潜力

成长潜力影响非玩家长期成长，玩家不遵循该限制。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 基本定型，成长空间很低。 |
| 21-40 | 仍可成长，但速度缓慢。 |
| 41-60 | 正常成长空间。 |
| 61-80 | 成长快速，适合年轻或天赋强角色。 |
| 81-100 | 天才、幼年关键角色、觉醒前角色。 |

等级越高，成长潜力通常越低。可以使用：

```text
有效成长潜力 = 成长潜力 × (1 - 等级 / 120)
```

## 等级与数值表现力总标尺

该标尺用于等级、力量、攻击输出、抗性、行动能力等可直接体现规模的属性。0-9 为普通人范围，10 以上为超凡范围。非破坏型属性需要转换成对应表现：智力对应处理复杂度与推演规模，感知对应感知范围与细节捕捉，意志对应精神抗性，魅力对应影响范围与支配感。

| 数值 | 战力/规模表现 |
| --- | --- |
| 0-9 | 普通人范围，训练有素的人类也不超过 9。 |
| 10-15 | 单手破坏钢铁无副作用，或轻松破坏水泥墙壁无副作用。 |
| 16-19 | 可稳定破坏建筑局部结构，压制现代武装个体。 |
| 20 | 单纯力量能够压缩空气，破坏十几米长街道。 |
| 25 | 单纯力量能够破坏千人左右小镇。 |
| 30 | 单纯力量能够破坏万人左右小镇。 |
| 35 | 能破坏十万人规模城镇。 |
| 40 | 能破坏百万人城市。 |
| 45 | 能破坏千万人大都市。 |
| 50 | 能破坏法国、日本这类面积的国家。 |
| 60 | 大陆级到行星表层级。 |
| 70 | 行星级到恒星级。 |
| 80 | 星系级到宇宙级。 |
| 90 | 单体宇宙级到复数宇宙级。 |
| 100 | 多元宇宙级别。 |

## 身内能力数值表现

身内能力范围 0-100。不同世界观可以有不同表现上限，但同一作品内应保持一致。当前系统中，身内能力的最终值由升级体系累积而来：

```text
身内能力当前值 = 初始值 + 等级值 + 分配值 + 非玩家成长
```

- 初始值：角色首次入库时，根据角色资料、当前年龄、所处世界、进入时间点和当前处境推演出来。普通现代人通常落在 1-9，超凡角色可更高。
- 等级值：真实升级时自动获得。当前规则为每升 1 级自动分配 2 点到身内能力，按职业/身份/技能倾向和短板加权。
- 分配值：玩家消耗自由属性点手动投入。当前规则为每升 1 级获得 1 点自由属性点，初始等级不发放。
- 非玩家成长：非玩家角色在时间流逝、训练、学习、战斗、剧情压力中，由 AI 根据努力方向分配。

数值解释必须同时看“当前值”和“来源”。例如力量 8 可以是“初始 8 的训练者”，也可以是“初始 4 + 等级 2 + 分配 2 的成长者”。

### 通用区间

| 数值段 | 通用含义 | 升级体系解释 |
| --- | --- | --- |
| 0 | 缺失、残损或几乎无法发挥。 | 通常只因重伤、诅咒、残疾、封印或极端剧情出现。 |
| 1-3 | 明显薄弱。 | 初始值偏低；需要长期成长或自由点补足。 |
| 4-6 | 普通人平均。 | 现代普通人、一般学生、普通职员常见区间。 |
| 7-9 | 普通人优秀到人类训练上限。 | 运动员、军人、专家、强意志者可在初始或早期成长达到。 |
| 10-15 | 初入超凡。 | 必须有明确世界观强化、特殊训练、魔术/异能、长期升级或大量分配。 |
| 16-19 | 稳定超凡。 | 已脱离现代人范畴，普通武装个体难以抗衡。 |
| 20-24 | 街区级表现。 | 能在对应领域影响街区级冲突、环境或复杂系统。 |
| 25-34 | 小镇级到万人小镇级表现。 | 通常是作品主力、高阶超凡者或长期成长结果。 |
| 35-49 | 城镇级到大都市级表现。 | 需要强世界观支撑，普通现实身份不能自然达到。 |
| 50-69 | 国家级到大陆/行星表层级表现。 | 神话、顶级英灵、规格外存在或重大突破。 |
| 70-89 | 行星到宇宙级表现。 | 极少数宇宙级角色，必须由设定或剧情突破支撑。 |
| 90-100 | 单体宇宙到多元宇宙级表现。 | 只能用于最高规格存在，普通升级不能随意堆到该段。 |

### 力量

力量衡量肌肉力量、爆发力、负重、近战压制和直接破坏。升级自动点通常来自战斗、运动、士兵、骑士、武者等成长模板；玩家分配点代表刻意强化肉体输出。

| 数值段 | 力量表现 |
| --- | --- |
| 0 | 无法正常发力，可能瘫痪、重伤或被封印。 |
| 1-3 | 虚弱，搬运和近战明显吃力。 |
| 4-6 | 普通成人力量。 |
| 7-9 | 训练者、人类强壮者、优秀运动员。 |
| 10-15 | 可无副作用破坏钢铁/水泥级目标，徒手压制普通武装个体。 |
| 16-19 | 稳定破坏建筑局部结构，近战冲击足以撕开普通防线。 |
| 20-24 | 可压缩空气、破坏十几米街道，拳脚本身具有环境破坏。 |
| 25-34 | 小镇级破坏力，力量冲突会改变地形。 |
| 35-49 | 城镇到大都市级破坏力。 |
| 50-69 | 国家级到大陆级破坏力。 |
| 70-100 | 行星级到多元宇宙级破坏力。 |

### 敏捷

敏捷衡量速度、反应、协调、闪避、先手与连续行动。升级自动点通常来自战斗、刺客、运动、潜行、射击、剑术等模板；自由点代表刻意强化机动和反应。

| 数值段 | 敏捷表现 |
| --- | --- |
| 0 | 几乎无法协调动作，可能被束缚、麻痹或失衡。 |
| 1-3 | 笨拙、反应慢，容易跌倒或被命中。 |
| 4-6 | 普通人移动和反应。 |
| 7-9 | 训练者，短跑、格斗、运动表现优秀。 |
| 10-15 | 肉眼难以跟上，可瞬间跨越房间或闪避普通火器。 |
| 16-19 | 可稳定压制现代武装个体，连续动作接近残影。 |
| 20-24 | 高速机动产生音爆或空气压缩，覆盖街区级战斗节奏。 |
| 25-34 | 可在小镇规模内高速转移或同时处理多点威胁。 |
| 35-49 | 城镇到大都市级机动，普通战场无法限制。 |
| 50-69 | 国家级到大陆级机动与反应。 |
| 70-100 | 行星级到多元宇宙级速度、反应或行动频率。 |

### 体质

体质衡量承伤、恢复、耐力基础、抗病抗毒和环境适应。升级自动点常来自战斗、训练、长期生存、肉体强化；自由点代表刻意提高生存上限。生命力和精力最大值会直接读取体质。

| 数值段 | 体质表现 |
| --- | --- |
| 0 | 身体濒临崩溃，无法维持正常生命活动。 |
| 1-3 | 病弱、易伤、恢复慢。 |
| 4-6 | 普通健康水平。 |
| 7-9 | 强健、耐久好，训练者或体力工作者。 |
| 10-15 | 可承受钢铁/水泥级冲击，恢复和抗性明显超人。 |
| 16-19 | 可在建筑级冲击、毒素、极端疲劳中维持行动。 |
| 20-24 | 可承受街区级冲击或极端环境。 |
| 25-34 | 小镇级耐久与恢复，普通武器难以造成决定性伤害。 |
| 35-49 | 城镇到大都市级承伤，生命池远超普通生物。 |
| 50-69 | 国家级到大陆级耐久或恢复。 |
| 70-100 | 行星级到多元宇宙级生存性。 |

### 智力

智力衡量理解、推理、记忆、知识运用、复杂技能学习和战术推演。升级自动点常来自学生、学者、医生、魔术师、研究者、技术职业；自由点代表刻意学习和思维强化。学习能力会读取智力并影响习得能力经验效率。

| 数值段 | 智力表现 |
| --- | --- |
| 0 | 无法进行稳定理解或记忆。 |
| 1-3 | 理解明显困难，只能处理简单任务。 |
| 4-6 | 普通教育与生活判断水平。 |
| 7-9 | 优秀学生、专业从业者、逻辑强者。 |
| 10-15 | 超凡计算/理解，能快速掌握复杂术式或跨领域知识。 |
| 16-19 | 稳定处理超凡系统、战术网络或高压推演。 |
| 20-24 | 可短时间处理城市级复杂局势。 |
| 25-34 | 可推演小镇到万人组织级系统。 |
| 35-49 | 可推演城镇到大都市级系统、组织或战局。 |
| 50-69 | 国家级到大陆级系统推演。 |
| 70-100 | 行星级到多元宇宙级结构理解。 |

### 感知

感知衡量观察、直觉、危险预判、索敌、异常察觉和细节捕捉。升级自动点常来自侦察、战斗、弓手、刺客、调查、魔术感知等模板；自由点代表刻意训练感官和直觉。精神稳定、命中、反偷袭会读取感知。

| 数值段 | 感知表现 |
| --- | --- |
| 0 | 感官或直觉近乎失效。 |
| 1-3 | 迟钝，容易漏掉明显线索。 |
| 4-6 | 普通观察力。 |
| 7-9 | 敏锐，能注意细节和危险征兆。 |
| 10-15 | 可察觉墙后、远距离杀意或高速动作。 |
| 16-19 | 稳定发现超凡异常、伏击和隐蔽动作。 |
| 20-24 | 可覆盖街区级异常或战斗态势。 |
| 25-34 | 可把握小镇级范围的危险、气息或信息变化。 |
| 35-49 | 城镇到大都市级宏观感知。 |
| 50-69 | 国家级到大陆级异常感知或宏观变化捕捉。 |
| 70-100 | 行星级到多元宇宙级结构波动感知。 |

### 意志

意志衡量抗压、忍耐、精神抵抗、专注、自我维持和目标坚持。升级自动点常来自骑士、王者、复仇者、受创后坚持、魔术师、领袖等模板；自由点代表刻意磨炼精神。精神稳定最大值和精神抗性会读取意志。

| 数值段 | 意志表现 |
| --- | --- |
| 0 | 意志崩溃，难以维持自我。 |
| 1-3 | 容易动摇、恐惧、放弃。 |
| 4-6 | 普通人的抗压和坚持。 |
| 7-9 | 坚韧、能承受高压训练或长期目标。 |
| 10-15 | 可抵抗常规精神压迫、肉体剧痛或轻度操控。 |
| 16-19 | 稳定抵抗超凡精神干涉和极端痛苦。 |
| 20-24 | 可承受街区级精神冲击或集体恐惧。 |
| 25-34 | 可在小镇级灾难、污染或信仰压迫中保持自我。 |
| 35-49 | 可承受城镇到大都市级精神污染或统治压力。 |
| 50-69 | 国家级到大陆级信仰、诅咒或精神冲击。 |
| 70-100 | 行星级到多元宇宙级压力下仍维持自我。 |

### 魅力

魅力衡量说服、亲和、威慑、统率、存在感和社会吸引力。升级自动点常来自领袖、偶像、贵族、王者、交涉者、演员等模板；自由点代表刻意塑造影响力。职业影响力、谈判、统率和社会关系成长会读取魅力。

| 数值段 | 魅力表现 |
| --- | --- |
| 0 | 极难建立正常社交影响，可能被恐惧、污染或诅咒排斥。 |
| 1-3 | 存在感弱，表达和影响力不足。 |
| 4-6 | 普通社交吸引力。 |
| 7-9 | 有亲和、威慑或领导气质。 |
| 10-15 | 可无副作用压制、号召或影响普通群体。 |
| 16-19 | 稳定影响组织、队伍或高压场合下的群体意志。 |
| 20-24 | 可影响街区级人群或组织。 |
| 25-34 | 可影响小镇到万人规模组织。 |
| 35-49 | 城镇到大都市级号召、威慑或社会支配感。 |
| 50-69 | 国家级到大陆级群众意志、信仰或统率。 |
| 70-100 | 行星级到多元宇宙级信仰吸引或支配感。 |

## 身内能力对其他属性的影响

| 身内能力 | 主要影响 | 表现力说明 |
| --- | --- | --- |
| 力量 | 攻击力、负重、近战伤害、破坏环境、压制动作 | 力量越高，徒手或重武器攻击力越高；10 以上进入超凡破坏。 |
| 敏捷 | 命中、闪避、先手、移动速度、行动能力、连击效率 | 敏捷越高，越容易减少受到的有效伤害，也更容易把攻击力转化为命中。 |
| 体质 | 生命力最大值、精力最大值、防御力、恢复力、抗病抗毒 | 体质越高，生命力与精力上限越高，受到同等攻击时生命力下降越少。 |
| 智力 | 学习能力、知识储备升级效率、复杂技能理解、战术推演 | 智力越高，学习知识/术式/复杂职业越快。 |
| 感知 | 精神稳定、侦察、危险预判、命中辅助、反偷袭 | 感知越高，越不容易被偷袭，也更容易发现弱点。 |
| 意志 | 精神稳定最大值、精神抗性、疼痛忍耐、专注施法 | 意志越高，精神稳定越不容易下降，濒死或受压时更能保持行动。 |
| 魅力 | 说服、威慑、领导、交涉、职业影响力 | 魅力越高，社会互动和统率型职业成长越快。 |

## 衍生能力：攻击力与防御力

攻击力和防御力是用于计算生命力增减的衍生能力，不是独立成长属性。

### 攻击力

攻击力主要由等级和力量决定，并受到敏捷、技能、武器、魔术、状态和战术影响。等级提供基础输出层级，力量提供主要破坏力差异。

```text
基础攻击力 = round((等级 × 4) + (力量 × 8))
最终攻击力 = 基础攻击力 + 攻击方式修正 + 技能修正 + 武器/魔术修正 + 情境修正
```

参考：

- 徒手攻击：主要看力量。
- 精密攻击：力量 + 敏捷 + 技能。
- 魔术攻击：魔力量/魔术回路/相关技能 + 智力或感知。
- 偷袭：攻击力不一定变高，但有效伤害上升。

### 防御力

防御力主要由等级和体质决定，并受到意志、护甲、防护术式、抗性、姿态和环境影响。等级提供基础抗性层级，体质提供主要肉体承伤差异。

```text
基础防御力 = round((等级 × 3) + (体质 × 8))
最终防御力 = 基础防御力 + 护甲/魔术防护 + 意志修正 + 情境修正
```

参考：

- 肉体承伤：主要看体质。
- 精神冲击：主要看意志，体质只作辅助。
- 毒、病、疲劳：主要看体质。
- 恐惧、操控、污染：主要看意志和精神稳定。

### 生命力增减

```text
有效伤害 = 最终攻击力 - 最终防御力 + 伤害倍率/克制/命中修正
若攻击被完全免疫：有效伤害 = 0
若攻击命中且未完全免疫：有效伤害 = max(1, 有效伤害)
生命力.current = max(0, 生命力.current - 有效伤害)
```

AI 判定时不需要机械暴露公式，但必须体现：

1. 高攻击力打低防御力，生命力明显下降。
2. 低攻击力打高防御力，可能只造成擦伤或无效。
3. 命中要害、偷袭、克制、状态异常会提高有效伤害。
4. 护甲、魔术防护、格挡、环境遮蔽会降低有效伤害。
5. 体质影响生命力最大值与防御力，力量影响攻击力。
6. 攻击力、防御力、生命力必须平衡：同级角色互相攻击应能造成有效消耗，但不应一击必杀；跨大等级攻击可以碾压。
7. 前文表现力标尺必须保留：50 级国家级角色的攻防与生命池都应远超 9 级普通人。

### 平衡示例

| 情况 | 预期结果 |
| --- | --- |
| 同级、攻防接近 | 每次命中消耗一部分生命力，需要多次有效攻击才能击败。 |
| 攻击力高于防御力 20% 左右 | 明显伤害，但通常不会满血秒杀。 |
| 攻击力高于防御力 100% 以上 | 可重创或秒杀，除非生命力极高或有特殊抗性。 |
| 防御力高于攻击力很多 | 擦伤、无效、被弹开，生命力下降极少或为 0。 |
| 等级差距跨越一个大层级 | 高层级角色可碾压低层级角色，符合表现力标尺。 |

## 习得能力等级与经验曲线

习得能力包括知识储备和技能。每项单独 lv1-lv7。

| 等级 | 描述 | nextExp |
| --- | --- | --- |
| lv1 | 入门，知道基本概念或能做最简单动作。 | 100 |
| lv2 | 初学，能在低压环境稳定使用。 | 250 |
| lv3 | 熟练，能处理常见情况。 | 600 |
| lv4 | 专业，能应对复杂情况。 | 1400 |
| lv5 | 专家，能创新或指导他人。 | 3200 |
| lv6 | 大师，领域内极少数高位者。 | 7200 |
| lv7 | 传说，世界观顶级或规格外。 | max |

### 习得能力经验获取

```text
获得经验 = 基础经验 × 学习能力倍率 × 相关身内能力倍率 × 实践质量倍率 × 难度倍率
```

相关身内能力倍率：

```text
相关身内能力倍率 = 0.6 + 平均相关身内能力 / 100
```

实践质量倍率：

- 看书/听讲：0.5-0.8
- 普通练习：1.0
- 实战/高压实践：1.2-2.0
- 名师指导：1.2-1.8
- 生死突破：2.0-3.0，但可能带来伤害或精神损耗。

## 职业等级与经验曲线

职业等级范围 lv1-lv7。职业不是临时身份，而是角色能够长期承担的一套社会功能。

| 职业等级 | 表现 |
| --- | --- |
| lv1 | 见习或刚入门。 |
| lv2 | 能完成基础职责。 |
| lv3 | 独立从业。 |
| lv4 | 资深从业者。 |
| lv5 | 专家或核心成员。 |
| lv6 | 大师、权威或高阶职位。 |
| lv7 | 传说级、时代代表或组织顶点。 |

职业经验依赖：

1. 相关习得能力等级。
2. 相关身内能力。
3. 实际履职时间。
4. 成果质量。
5. 社会承认或组织认证。

职业失去规则：

- 失去阵营身份不等于失去职业能力。
- 长期失忆、身体失能、设定改变，才可能使职业等级下降或失效。
- 阵营地位变化只更新社会属性，不影响职业等级本身。

## 数值生成注意事项

1. 不要为了戏剧性把所有主角都设为高数值。
2. 幼年角色可以成长潜力高，但当前生命力、行动能力、力量通常较低。
3. 强大角色也可能精神稳定低、魅力低或学习能力一般。
4. 普通人的数值集中在 35-60，不能动辄 80+。
5. 超常数值必须有世界观依据，例如神秘强化、英灵、改造、怪物血统。
6. 外部身份、家族资源、组织地位应进入社会属性，不应提高身内能力。
7. 已掌握知识和技能应进入习得能力，不应混入智力或学习能力。
