# 能力与升级体系设计

本文件是能力、等级、经验值与成长曲线的设计文档。它用于指导系统如何解释数值，不应整段塞入 AI 角色生成提示词。AI 提示词应优先引用 `ability-schema.md` 中的输出结构与规则。

## 设计目标

1. 等级能表达角色综合成长，但不能替代具体能力。
2. 基础能力体现当前生存状态，允许短期波动。
3. 身内能力体现底层资质，成长慢，不随单次事件随意变化。
4. 习得能力、技能、职业拥有独立等级与经验，能表现后天学习过程。
5. 非玩家角色没有机械刷怪升级公式，应根据剧情间隔、成长潜力、环境与经历推断成长。
6. 玩家角色可以使用明确经验公式，保证可玩性。

## 角色等级（1-100）

角色等级是综合评价，不等于战斗力。它综合考虑：身内能力、习得能力、职业成熟度、世界观强度、当前年龄与经历。

| 等级段 | 表现 |
| --- | --- |
| 1-5 | 幼童、弱者、无经验普通人。 |
| 6-15 | 普通人、学生、缺少训练者。 |
| 16-25 | 有稳定生活技能或基础训练者。 |
| 26-40 | 专业人士、普通战斗员、成熟工作者。 |
| 41-55 | 精英人员、老练魔术师、优秀战士。 |
| 56-70 | 领域高手、危险人物、强力魔术师。 |
| 71-85 | 英雄级、怪物级、人类极限或神秘强化核心角色。 |
| 86-95 | 世界观顶级存在。 |
| 96-100 | 规格外，不应频繁出现。 |

## 经验值曲线

### 玩家角色经验曲线

玩家角色可使用明确升级公式：

```text
nextExp(level) = round(100 * level^1.65)
```

特点：

- 前期升级快，便于反馈。
- 中后期增长明显放缓。
- 允许通过任务、战斗、学习、训练、剧情突破获得经验。

### 非玩家角色成长方式

非玩家角色不使用固定刷经验公式，而使用成长推断：

```text
成长量 = 时间跨度 × 成长潜力 × 环境强度 × 实践频率 × 教育/训练质量 × 剧情压力修正
```

解释：

- 时间跨度：角色两次出场之间经过的时间。
- 成长潜力：0-100，越高越容易成长。
- 环境强度：日常环境低，战场/高压训练高。
- 实践频率：是否经常使用相关能力。
- 教育/训练质量：是否有导师、组织、资源、体系化训练。
- 剧情压力修正：重大创伤、觉醒、魔术改造等事件可改变成长。

非玩家再次出现时，AI 应给出“增长、停滞、退步”的解释，而不是直接套公式。

## 基础能力数值曲线

基础能力多为当前值/最大值。最大值受身内能力、等级、年龄、种族、世界观强化影响；当前值受剧情即时状态影响。

### 生命力

生命力表示身体完整、生存状态与承伤余量。

| 当前值比例 | 表现 |
| --- | --- |
| 100% | 状态完整。 |
| 75%-99% | 轻微擦伤或不影响行动。 |
| 50%-74% | 明显受伤，行动受影响。 |
| 25%-49% | 重伤，持续行动困难。 |
| 1%-24% | 濒死或几乎失去行动能力。 |
| 0% | 死亡、昏迷或剧情判定失去生存能力。 |

### 精力

精力表示体能和持续行动余量。

| 当前值比例 | 表现 |
| --- | --- |
| 80%-100% | 行动顺畅。 |
| 50%-79% | 正常消耗。 |
| 25%-49% | 疲惫，爆发力下降。 |
| 1%-24% | 极度疲惫，难以持续行动。 |
| 0% | 无法主动行动或需要立即休息。 |

### 饱食度 / 水分

饱食度和水分主要服务生存体验，不与等级直接挂钩。

- 饱食度低会影响精力恢复、精神稳定与行动能力。
- 水分低会快速影响生命力、精力与判断。
- 职业和环境会影响消耗速度，例如士兵、矿工、运动员、荒野旅行者消耗更快。

### 疲劳度

疲劳度是负面累积值，越高越糟。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 清醒。 |
| 21-40 | 略有疲倦。 |
| 41-60 | 明显疲劳。 |
| 61-80 | 判断下降、行动迟缓。 |
| 81-100 | 接近崩溃，可能昏睡或失误。 |

### 学习能力

学习能力影响习得能力经验获取效率。

```text
学习经验倍率 = 0.5 + 学习能力 / 100
```

例：

- 学习能力 20：0.7 倍。
- 学习能力 50：1.0 倍。
- 学习能力 90：1.4 倍。

### 精神稳定

精神稳定有当前值和最大值。当前值短期波动，最大值代表心理韧性上限。

- 受恐惧、操控、创伤、压力、精神攻击影响下降。
- 受休息、安抚、熟悉环境、信任关系影响恢复。
- 意志高的人精神稳定最大值通常更高。

### 成长潜力

成长潜力影响非玩家长期成长，玩家不遵循该限制。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 基本定型，成长空间很低。 |
| 21-40 | 仍可成长，但速度缓慢。 |
| 41-60 | 正常成长空间。 |
| 61-80 | 成长快速，适合年轻或天赋强角色。 |
| 81-100 | 天才、幼年关键角色、觉醒前角色。 |

等级越高，成长潜力通常越低。可以使用：

```text
有效成长潜力 = 成长潜力 × (1 - 等级 / 120)
```

## 身内能力数值表现

身内能力范围 0-100。不同世界观可以有不同表现上限，但同一作品内应保持一致。

### 力量参考

| 数值 | 表现参考 |
| --- | --- |
| 10 | 虚弱儿童或病弱者。 |
| 30 | 普通成年人的较弱水平。 |
| 50 | 健康成年人或普通训练者。 |
| 70 | 专业力量训练者。 |
| 85 | 非常人级，能轻易压制普通人。 |
| 95 | 怪物级，可造成夸张破坏。 |
| 100 | 世界观规格外。 |

不要机械写“拳头 10 吨”给普通角色；只有世界观支持的超常存在才允许出现吨级力量。

### 敏捷参考

| 数值 | 表现参考 |
| --- | --- |
| 30 | 反应慢，动作笨拙。 |
| 50 | 普通健康成年人。 |
| 70 | 训练者、优秀运动员。 |
| 85 | 人类极限附近，反应极快。 |
| 95 | 超常存在，普通人难以捕捉动作。 |

速度表现必须符合世界观。普通人不能写 10km/s；这类速度只属于明确超常或神秘存在。

### 体质参考

| 数值 | 表现参考 |
| --- | --- |
| 30 | 易病、恢复慢。 |
| 50 | 普通健康水平。 |
| 70 | 耐久优秀，恢复较快。 |
| 85 | 远超常人，能承受严苛环境。 |
| 95 | 怪物级生命力或神秘强化肉体。 |

### 智力参考

| 数值 | 表现参考 |
| --- | --- |
| 30 | 理解复杂问题困难。 |
| 50 | 普通人。 |
| 70 | 学习快，逻辑清晰。 |
| 85 | 天才或专家级理解力。 |
| 95 | 规格外思考能力。 |

### 感知参考

| 数值 | 表现参考 |
| --- | --- |
| 30 | 容易忽略细节。 |
| 50 | 普通观察力。 |
| 70 | 敏锐，能察觉异常。 |
| 85 | 极强直觉与洞察。 |
| 95 | 超常感知、神秘感应或怪物级直觉。 |

### 意志参考

| 数值 | 表现参考 |
| --- | --- |
| 30 | 容易崩溃或放弃。 |
| 50 | 普通抗压。 |
| 70 | 坚定，能承受高压。 |
| 85 | 极强精神抵抗。 |
| 95 | 近乎不可撼动。 |

### 魅力参考

| 数值 | 表现参考 |
| --- | --- |
| 30 | 存在感弱或难以说服他人。 |
| 50 | 普通社交影响力。 |
| 70 | 有明显吸引力或威慑。 |
| 85 | 领袖、偶像或强压迫感。 |
| 95 | 规格外人格魅力或超常威仪。 |

## 习得能力等级与经验曲线

习得能力包括知识储备和技能。每项单独 lv1-lv7。

| 等级 | 描述 | nextExp |
| --- | --- | --- |
| lv1 | 入门，知道基本概念或能做最简单动作。 | 100 |
| lv2 | 初学，能在低压环境稳定使用。 | 250 |
| lv3 | 熟练，能处理常见情况。 | 600 |
| lv4 | 专业，能应对复杂情况。 | 1400 |
| lv5 | 专家，能创新或指导他人。 | 3200 |
| lv6 | 大师，领域内极少数高位者。 | 7200 |
| lv7 | 传说，世界观顶级或规格外。 | max |

### 习得能力经验获取

```text
获得经验 = 基础经验 × 学习能力倍率 × 相关身内能力倍率 × 实践质量倍率 × 难度倍率
```

相关身内能力倍率：

```text
相关身内能力倍率 = 0.6 + 平均相关身内能力 / 100
```

实践质量倍率：

- 看书/听讲：0.5-0.8
- 普通练习：1.0
- 实战/高压实践：1.2-2.0
- 名师指导：1.2-1.8
- 生死突破：2.0-3.0，但可能带来伤害或精神损耗。

## 职业等级与经验曲线

职业等级范围 lv1-lv7。职业不是临时身份，而是角色能够长期承担的一套社会功能。

| 职业等级 | 表现 |
| --- | --- |
| lv1 | 见习或刚入门。 |
| lv2 | 能完成基础职责。 |
| lv3 | 独立从业。 |
| lv4 | 资深从业者。 |
| lv5 | 专家或核心成员。 |
| lv6 | 大师、权威或高阶职位。 |
| lv7 | 传说级、时代代表或组织顶点。 |

职业经验依赖：

1. 相关习得能力等级。
2. 相关身内能力。
3. 实际履职时间。
4. 成果质量。
5. 社会承认或组织认证。

职业失去规则：

- 失去阵营身份不等于失去职业能力。
- 长期失忆、身体失能、设定改变，才可能使职业等级下降或失效。
- 阵营地位变化只更新社会属性，不影响职业等级本身。

## 数值生成注意事项

1. 不要为了戏剧性把所有主角都设为高数值。
2. 幼年角色可以成长潜力高，但当前生命力、行动能力、力量通常较低。
3. 强大角色也可能精神稳定低、魅力低或学习能力一般。
4. 普通人的数值集中在 35-60，不能动辄 80+。
5. 超常数值必须有世界观依据，例如神秘强化、英灵、改造、怪物血统。
6. 外部身份、家族资源、组织地位应进入社会属性，不应提高身内能力。
7. 已掌握知识和技能应进入习得能力，不应混入智力或学习能力。
