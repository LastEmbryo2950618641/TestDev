# 能力与升级体系设计

本文件是能力、等级、经验值与成长曲线的设计文档。它用于指导系统如何解释数值，不应整段塞入 AI 角色生成提示词。AI 提示词应优先引用 `ability-schema.md` 中的输出结构与规则。

## 设计目标

1. 等级能表达角色综合成长，但不能替代具体能力。
2. 基础能力体现当前生存状态，允许短期波动。
3. 身内能力体现底层资质，成长慢，不随单次事件随意变化。
4. 习得能力、技能、职业拥有独立等级与经验，能表现后天学习过程。
5. 非玩家角色没有机械刷怪升级公式，应根据剧情间隔、成长潜力、环境与经历推断成长。
6. 玩家角色可以使用明确经验公式，保证可玩性。

## 角色等级（1-100）

角色等级是综合评价，不等于战斗力。它综合考虑：身内能力、习得能力、职业成熟度、世界观强度、当前年龄与经历。

| 等级段 | 表现 |
| --- | --- |
| 1-9 | 普通人范围：幼童、弱者、普通成年人、训练有素的人类上限都在此范围内。 |
| 10-15 | 初入超凡：可单手破坏钢铁且无副作用，或轻松破坏水泥墙壁且无副作用。 |
| 16-19 | 稳定超凡：能压制现代武装个体，小范围破坏建筑结构。 |
| 20-24 | 街区级：单纯力量可压缩空气，破坏十几米长街道。 |
| 25-29 | 千人小镇级：单纯力量足以破坏约千人规模小镇。 |
| 30-34 | 万人小镇级：单纯力量足以破坏万人左右小镇。 |
| 35-39 | 十万人城镇级：可破坏十万人规模城镇。 |
| 40-44 | 百万人城市级：可破坏百万人规模城市。 |
| 45-49 | 千万人大都市级：可破坏千万人规模大都市。 |
| 50-59 | 国家级：可破坏法国、日本这类面积的国家。 |
| 60-69 | 大陆级到行星表层级。 |
| 70-79 | 行星级到恒星级。 |
| 80-89 | 星系级到宇宙级。 |
| 90-99 | 单体宇宙级到复数宇宙级。 |
| 100 | 多元宇宙级别。 |

## 经验值曲线

### 玩家角色经验曲线

玩家角色可使用明确升级公式：

```text
nextExp(level) = round(100 * level^1.65)
```

特点：

- 前期升级快，便于反馈。
- 中后期增长明显放缓。
- 允许通过任务、战斗、学习、训练、剧情突破获得经验。

### 非玩家角色成长方式

非玩家角色不使用固定刷经验公式，而使用成长推断：

```text
成长量 = 时间跨度 × 成长潜力 × 环境强度 × 实践频率 × 教育/训练质量 × 剧情压力修正
```

解释：

- 时间跨度：角色两次出场之间经过的时间。
- 成长潜力：0-100，越高越容易成长。
- 环境强度：日常环境低，战场/高压训练高。
- 实践频率：是否经常使用相关能力。
- 教育/训练质量：是否有导师、组织、资源、体系化训练。
- 剧情压力修正：重大创伤、觉醒、魔术改造等事件可改变成长。

非玩家再次出现时，AI 应给出“增长、停滞、退步”的解释，而不是直接套公式。

## 等级成长与自由属性点

角色获得个人经验并升级时，所有“与个人等级有关”的能力必须有明确成长算法，不能只增加等级数字。

### 升级结算顺序

```text
1. 扣除本级经验，个人等级 +1
2. 根据成长模板自动增加身内能力
3. 发放自由属性点
4. 重算生命力、精力、精神稳定、行动能力、攻防衍生
5. 写入升级记录
```

### 身内能力自动成长

每次个人等级提升时，系统根据角色身份、职业、技能和人物资料推导成长模板，并给身内能力加点：

```text
每级自动成长点 = 2 点
成长权重来源 = 角色职业/身份 + 已有技能 linkedStats + 当前身内能力短板
```

规则：

- 战斗、运动、士兵、骑士、武者：优先力量、敏捷、体质。
- 学生、学者、医生、魔术师、研究者：优先智力、感知、意志。
- 领袖、偶像、贵族、交涉型角色：优先魅力、意志、感知。
- 普通现代人或身份不明确：按当前短板轮流补齐，避免单项过高。
- 单项身内能力上限为 100；已满的属性跳过。

### 自由属性点

玩家角色或可被玩家长期培养的角色，每升 1 级获得自由属性点：

```text
每级自由属性点 = 1 点
可分配范围 = 力量、敏捷、体质、智力、感知、意志、魅力
```

自由属性点暂时不自动消费，写入 `free_attribute_points`，由后续 UI 或剧情奖励分配；非玩家角色也可保留该字段，表示可成长余量。

### 派生属性重算

等级或身内能力变化后必须重算：

- 生命力最大值：等级、体质。
- 精力最大值：等级、体质、训练修正。
- 精神稳定最大值：意志。
- 行动能力最大值：敏捷、体质。
- 学习能力：智力为主，感知/意志辅助。
- 攻击力、防御力、战斗模拟。

## 基础能力数值曲线

基础能力多为当前值/最大值。最大值受身内能力、等级、年龄、种族、世界观强化影响；当前值受剧情即时状态影响。

### 生命力

生命力表示身体完整、生存状态与承伤余量。生命力是数值池，不是固定 0-100 百分比；最大值与等级和体质挂钩。

```text
生命力.max = round((等级 × 10) + (体质 × 8) + 种族/体型修正 + 特殊体质修正)
```

说明：

- 等级提供基础生命池，保证高等级角色不会被低级攻击轻易秒杀。
- 体质提供主要耐久差异，体质越高生命力上限越高。
- 种族/体型修正用于巨人、怪物、英灵、病弱幼童等特殊身体。
- 生命力数值必须和前文 0-100 表现力标尺平衡：超凡角色生命池可远高于普通人，但不能让同级攻击完全失效。

| 当前值比例 | 表现 |
| --- | --- |
| 100% | 状态完整。 |
| 75%-99% | 轻微擦伤或不影响行动。 |
| 50%-74% | 明显受伤，行动受影响。 |
| 25%-49% | 重伤，持续行动困难。 |
| 1%-24% | 濒死或几乎失去行动能力。 |
| 0% | 死亡、昏迷或剧情判定失去生存能力。 |

### 精力

精力表示体能和持续行动余量。精力也是数值池，最大值与等级和体质挂钩。

```text
精力.max = round((等级 × 8) + (体质 × 5) + 职业/训练修正 + 特殊体质修正)
```

说明：

- 等级越高，持续行动和连续释放能力越强。
- 体质越高，精力上限越高，恢复和耐疲劳更好。
- 职业/训练修正用于运动员、士兵、魔术师、病弱者等差异。
- 精力 current 会因行动、战斗、施法、奔跑、饥饿、缺水、疲劳而下降。

| 当前值比例 | 表现 |
| --- | --- |
| 80%-100% | 行动顺畅。 |
| 50%-79% | 正常消耗。 |
| 25%-49% | 疲惫，爆发力下降。 |
| 1%-24% | 极度疲惫，难以持续行动。 |
| 0% | 无法主动行动或需要立即休息。 |

### 饱食度 / 水分

饱食度和水分主要服务生存体验，不与等级直接挂钩。

- 饱食度低会影响精力恢复、精神稳定与行动能力。
- 水分低会快速影响生命力、精力与判断。
- 职业和环境会影响消耗速度，例如士兵、矿工、运动员、荒野旅行者消耗更快。

### 疲劳度

疲劳度是负面累积值，越高越糟。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 清醒。 |
| 21-40 | 略有疲倦。 |
| 41-60 | 明显疲劳。 |
| 61-80 | 判断下降、行动迟缓。 |
| 81-100 | 接近崩溃，可能昏睡或失误。 |

### 学习能力

学习能力影响习得能力经验获取效率。

```text
学习经验倍率 = 0.5 + 学习能力 / 100
```

例：

- 学习能力 20：0.7 倍。
- 学习能力 50：1.0 倍。
- 学习能力 90：1.4 倍。

### 精神稳定

精神稳定有当前值和最大值。当前值短期波动，最大值代表心理韧性上限。

- 受恐惧、操控、创伤、压力、精神攻击影响下降。
- 受休息、安抚、熟悉环境、信任关系影响恢复。
- 意志高的人精神稳定最大值通常更高。

### 成长潜力

成长潜力影响非玩家长期成长，玩家不遵循该限制。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 基本定型，成长空间很低。 |
| 21-40 | 仍可成长，但速度缓慢。 |
| 41-60 | 正常成长空间。 |
| 61-80 | 成长快速，适合年轻或天赋强角色。 |
| 81-100 | 天才、幼年关键角色、觉醒前角色。 |

等级越高，成长潜力通常越低。可以使用：

```text
有效成长潜力 = 成长潜力 × (1 - 等级 / 120)
```

## 身内能力数值表现

身内能力范围 0-100。不同世界观可以有不同表现上限，但同一作品内应保持一致。

### 力量参考

力量直接套用“等级与数值表现力总标尺”：0-9 为普通人范围；10 开始可破坏钢铁或水泥墙；20 可压缩空气并破坏街道；50 达国家级；100 达多元宇宙级。普通角色不得超过 9，除非设定明确具备超凡力量。

### 敏捷参考

敏捷也遵循 0-9 普通人、10 以上超凡的规则。10-15 可表现为肉眼难以跟上、瞬间跨越房间或轻松闪避普通火器；20 以上可产生空气压缩、音爆或街区级高速机动；更高等级按总标尺扩大速度、反应与机动范围。

### 体质参考

体质按承伤、恢复、抗病、抗毒、耐环境能力体现。0-9 为普通人范围；10-15 可无副作用承受钢铁/水泥级冲击；20 以上可承受街区级冲击或极端环境；更高等级按总标尺扩大耐久与恢复规模。

### 智力参考

智力不直接等于破坏力。0-9 为普通人思考范围；10 以上进入超凡计算、理解、推演或学习能力。20 可在短时间处理城市级复杂局势；50 可推演国家级系统；100 可理解或推演多元宇宙级结构。

### 感知参考

感知按范围、精度、直觉与异常察觉体现。0-9 为普通人范围；10-15 可察觉墙后、远距离杀意或高速动作；20 可覆盖街区级异常；50 可覆盖国家级异常或宏观变化；100 可感知多元宇宙级结构波动。

### 意志参考

意志按精神抗性、专注、痛苦承受与自我维持体现。0-9 为普通人范围；10-15 可抵抗常规精神压迫或肉体剧痛；20 可抵抗街区级精神冲击；50 可承受国家级信仰、诅咒或精神污染；100 可在多元宇宙级压力下保持自我。

### 魅力参考

魅力按说服、亲和、威慑、统率、存在感与影响范围体现。0-9 为普通人范围；10-15 可无副作用压制或号召普通群体；20 可影响街区级人群或组织；50 可影响国家级群体意志；100 可形成多元宇宙级支配感或信仰吸引。

## 身内能力对其他属性的影响

| 身内能力 | 主要影响 | 表现力说明 |
| --- | --- | --- |
| 力量 | 攻击力、负重、近战伤害、破坏环境、压制动作 | 力量越高，徒手或重武器攻击力越高；10 以上进入超凡破坏。 |
| 敏捷 | 命中、闪避、先手、移动速度、行动能力、连击效率 | 敏捷越高，越容易减少受到的有效伤害，也更容易把攻击力转化为命中。 |
| 体质 | 生命力最大值、精力最大值、防御力、恢复力、抗病抗毒 | 体质越高，生命力与精力上限越高，受到同等攻击时生命力下降越少。 |
| 智力 | 学习能力、知识储备升级效率、复杂技能理解、战术推演 | 智力越高，学习知识/术式/复杂职业越快。 |
| 感知 | 精神稳定、侦察、危险预判、命中辅助、反偷袭 | 感知越高，越不容易被偷袭，也更容易发现弱点。 |
| 意志 | 精神稳定最大值、精神抗性、疼痛忍耐、专注施法 | 意志越高，精神稳定越不容易下降，濒死或受压时更能保持行动。 |
| 魅力 | 说服、威慑、领导、交涉、职业影响力 | 魅力越高，社会互动和统率型职业成长越快。 |

## 衍生能力：攻击力与防御力

攻击力和防御力是用于计算生命力增减的衍生能力，不是独立成长属性。

### 攻击力

攻击力主要由等级和力量决定，并受到敏捷、技能、武器、魔术、状态和战术影响。等级提供基础输出层级，力量提供主要破坏力差异。

```text
基础攻击力 = round((等级 × 4) + (力量 × 8))
最终攻击力 = 基础攻击力 + 攻击方式修正 + 技能修正 + 武器/魔术修正 + 情境修正
```

参考：

- 徒手攻击：主要看力量。
- 精密攻击：力量 + 敏捷 + 技能。
- 魔术攻击：魔力量/魔术回路/相关技能 + 智力或感知。
- 偷袭：攻击力不一定变高，但有效伤害上升。

### 防御力

防御力主要由等级和体质决定，并受到意志、护甲、防护术式、抗性、姿态和环境影响。等级提供基础抗性层级，体质提供主要肉体承伤差异。

```text
基础防御力 = round((等级 × 3) + (体质 × 8))
最终防御力 = 基础防御力 + 护甲/魔术防护 + 意志修正 + 情境修正
```

参考：

- 肉体承伤：主要看体质。
- 精神冲击：主要看意志，体质只作辅助。
- 毒、病、疲劳：主要看体质。
- 恐惧、操控、污染：主要看意志和精神稳定。

### 生命力增减

```text
有效伤害 = 最终攻击力 - 最终防御力 + 伤害倍率/克制/命中修正
若攻击被完全免疫：有效伤害 = 0
若攻击命中且未完全免疫：有效伤害 = max(1, 有效伤害)
生命力.current = max(0, 生命力.current - 有效伤害)
```

AI 判定时不需要机械暴露公式，但必须体现：

1. 高攻击力打低防御力，生命力明显下降。
2. 低攻击力打高防御力，可能只造成擦伤或无效。
3. 命中要害、偷袭、克制、状态异常会提高有效伤害。
4. 护甲、魔术防护、格挡、环境遮蔽会降低有效伤害。
5. 体质影响生命力最大值与防御力，力量影响攻击力。
6. 攻击力、防御力、生命力必须平衡：同级角色互相攻击应能造成有效消耗，但不应一击必杀；跨大等级攻击可以碾压。
7. 前文表现力标尺必须保留：50 级国家级角色的攻防与生命池都应远超 9 级普通人。

### 平衡示例

| 情况 | 预期结果 |
| --- | --- |
| 同级、攻防接近 | 每次命中消耗一部分生命力，需要多次有效攻击才能击败。 |
| 攻击力高于防御力 20% 左右 | 明显伤害，但通常不会满血秒杀。 |
| 攻击力高于防御力 100% 以上 | 可重创或秒杀，除非生命力极高或有特殊抗性。 |
| 防御力高于攻击力很多 | 擦伤、无效、被弹开，生命力下降极少或为 0。 |
| 等级差距跨越一个大层级 | 高层级角色可碾压低层级角色，符合表现力标尺。 |

## 习得能力等级与经验曲线

习得能力包括知识储备和技能。每项单独 lv1-lv7。

| 等级 | 描述 | nextExp |
| --- | --- | --- |
| lv1 | 入门，知道基本概念或能做最简单动作。 | 100 |
| lv2 | 初学，能在低压环境稳定使用。 | 250 |
| lv3 | 熟练，能处理常见情况。 | 600 |
| lv4 | 专业，能应对复杂情况。 | 1400 |
| lv5 | 专家，能创新或指导他人。 | 3200 |
| lv6 | 大师，领域内极少数高位者。 | 7200 |
| lv7 | 传说，世界观顶级或规格外。 | max |

### 习得能力经验获取

```text
获得经验 = 基础经验 × 学习能力倍率 × 相关身内能力倍率 × 实践质量倍率 × 难度倍率
```

相关身内能力倍率：

```text
相关身内能力倍率 = 0.6 + 平均相关身内能力 / 100
```

实践质量倍率：

- 看书/听讲：0.5-0.8
- 普通练习：1.0
- 实战/高压实践：1.2-2.0
- 名师指导：1.2-1.8
- 生死突破：2.0-3.0，但可能带来伤害或精神损耗。

## 职业等级与经验曲线

职业等级范围 lv1-lv7。职业不是临时身份，而是角色能够长期承担的一套社会功能。

| 职业等级 | 表现 |
| --- | --- |
| lv1 | 见习或刚入门。 |
| lv2 | 能完成基础职责。 |
| lv3 | 独立从业。 |
| lv4 | 资深从业者。 |
| lv5 | 专家或核心成员。 |
| lv6 | 大师、权威或高阶职位。 |
| lv7 | 传说级、时代代表或组织顶点。 |

职业经验依赖：

1. 相关习得能力等级。
2. 相关身内能力。
3. 实际履职时间。
4. 成果质量。
5. 社会承认或组织认证。

职业失去规则：

- 失去阵营身份不等于失去职业能力。
- 长期失忆、身体失能、设定改变，才可能使职业等级下降或失效。
- 阵营地位变化只更新社会属性，不影响职业等级本身。

## 数值生成注意事项

1. 不要为了戏剧性把所有主角都设为高数值。
2. 幼年角色可以成长潜力高，但当前生命力、行动能力、力量通常较低。
3. 强大角色也可能精神稳定低、魅力低或学习能力一般。
4. 普通人的数值集中在 35-60，不能动辄 80+。
5. 超常数值必须有世界观依据，例如神秘强化、英灵、改造、怪物血统。
6. 外部身份、家族资源、组织地位应进入社会属性，不应提高身内能力。
7. 已掌握知识和技能应进入习得能力，不应混入智力或学习能力。
