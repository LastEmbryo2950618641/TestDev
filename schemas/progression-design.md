# 能力与升级体系设计

本文件是能力、等级、经验值与成长曲线的设计文档。它用于指导系统如何解释数值，不应整段塞入 AI 角色生成提示词。AI 提示词应优先引用 `ability-schema.md` 中的输出结构与规则。

## 设计目标

1. 等级能表达角色综合成长，但不能替代具体能力。
2. 基础能力体现当前生存状态，允许短期波动。
3. 身内能力体现底层资质，成长慢，不随单次事件随意变化。
4. 习得能力、技能、职业拥有独立等级与经验，能表现后天学习过程。
5. 非玩家角色没有机械刷怪升级公式，应根据剧情间隔、成长潜力、环境与经历推断成长。
6. 玩家角色可以使用明确经验公式，保证可玩性。

## 角色等级（1-100）

角色等级是综合评价，不等于战斗力。它综合考虑：身内能力、习得能力、职业成熟度、世界观强度、当前年龄与经历。

| 等级段 | 表现 |
| --- | --- |
| 1-9 | 普通人范围：幼童、弱者、普通成年人、训练有素的人类上限都在此范围内。 |
| 10-15 | 初入超凡：可单手破坏钢铁且无副作用，或轻松破坏水泥墙壁且无副作用。 |
| 16-19 | 稳定超凡：能压制现代武装个体，小范围破坏建筑结构。 |
| 20-24 | 街区级：单纯力量可压缩空气，破坏十几米长街道。 |
| 25-29 | 千人小镇级：单纯力量足以破坏约千人规模小镇。 |
| 30-34 | 万人小镇级：单纯力量足以破坏万人左右小镇。 |
| 35-39 | 十万人城镇级：可破坏十万人规模城镇。 |
| 40-44 | 百万人城市级：可破坏百万人规模城市。 |
| 45-49 | 千万人大都市级：可破坏千万人规模大都市。 |
| 50-59 | 国家级：可破坏法国、日本这类面积的国家。 |
| 60-69 | 大陆级到行星表层级。 |
| 70-79 | 行星级到恒星级。 |
| 80-89 | 星系级到宇宙级。 |
| 90-99 | 单体宇宙级到复数宇宙级。 |
| 100 | 多元宇宙级别。 |

## 经验值曲线

### 玩家角色经验曲线

玩家角色可使用明确升级公式：

```text
nextExp(level) = round(100 * level^1.65)
```

特点：

- 前期升级快，便于反馈。
- 中后期增长明显放缓。
- 允许通过任务、战斗、学习、训练、剧情突破获得经验。

### 非玩家角色成长方式

非玩家角色不使用固定刷经验公式，而使用成长推断：

```text
成长量 = 时间跨度 × 成长潜力 × 环境强度 × 实践频率 × 教育/训练质量 × 剧情压力修正
```

解释：

- 时间跨度：角色两次出场之间经过的时间。
- 成长潜力：0-100，越高越容易成长。
- 环境强度：日常环境低，战场/高压训练高。
- 实践频率：是否经常使用相关能力。
- 教育/训练质量：是否有导师、组织、资源、体系化训练。
- 剧情压力修正：重大创伤、觉醒、魔术改造等事件可改变成长。

非玩家再次出现时，AI 应给出“增长、停滞、退步”的解释，而不是直接套公式。

## 等级成长与自由属性点

角色获得个人经验并升级时，所有“与个人等级有关”的能力必须有明确成长算法，不能只增加等级数字。

### 升级结算顺序

```text
1. 扣除本级经验，个人等级 +1
2. 根据成长模板自动增加身内能力
3. 发放自由属性点
4. 重算生命力、精力、精神稳定、行动能力、攻防衍生
5. 写入升级记录
```

### 身内能力自动成长

每次个人等级提升时，系统根据角色身份、职业、技能和人物资料推导成长模板，并给身内能力加点：

```text
每级自动成长点 = 2 点
成长权重来源 = 角色职业/身份 + 已有技能 linkedStats + 当前身内能力短板
```

规则：

- 战斗、运动、士兵、骑士、武者：优先力量、敏捷、体质。
- 学生、学者、医生、魔术师、研究者：优先智力、感知、意志。
- 领袖、偶像、贵族、交涉型角色：优先魅力、意志、感知。
- 普通现代人或身份不明确：按当前短板轮流补齐，避免单项过高。
- 单项身内能力上限为 100；已满的属性跳过。

### 自由属性点

玩家角色或可被玩家长期培养的角色，每升 1 级获得自由属性点：

```text
每级自由属性点 = 1 点
可分配范围 = 力量、敏捷、体质、智力、感知、意志、魅力
```

自由属性点暂时不自动消费，写入 `free_attribute_points`，由后续 UI 或剧情奖励分配；非玩家角色也可保留该字段，表示可成长余量。初始等级不发放自由属性点，只有真实升级才发放。

### 身内能力来源展示

每个身内能力在 UI 展示时必须能展开查看来源：

```text
当前值 = 初始值 + 等级值 + 分配值 + 非玩家成长
```

- 初始值：角色首次入库时，根据资料和当前情况推演出的基础身内值；旧存档无来源时，当前值先归入初始值。
- 等级值：个人等级实际升级时由系统自动成长加上的值。
- 分配值：玩家消耗自由属性点手动分配得到的值。
- 非玩家成长：非玩家角色在时间流逝、训练、努力方向、剧情压力中自动分配得到的值。

### 派生属性重算

等级或身内能力变化后必须重算：

- 生命力最大值：等级、体质。
- 精力最大值：等级、体质、训练修正。
- 精神稳定最大值：意志。
- 行动能力最大值：敏捷、体质。
- 学习能力：智力为主，感知/意志辅助。
- 攻击力、防御力、战斗模拟。

## 基础能力数值曲线

基础能力多为当前值/最大值。最大值受身内能力、等级、年龄、种族、世界观强化影响；当前值受剧情即时状态影响。

### 生命力

生命力表示身体完整、生存状态与承伤余量。生命力是数值池，不是固定 0-100 百分比；最大值与等级和体质挂钩。

```text
生命力.max = round((等级 × 10) + (体质 × 8) + 种族/体型修正 + 特殊体质修正)
```

说明：

- 等级提供基础生命池，保证高等级角色不会被低级攻击轻易秒杀。
- 体质提供主要耐久差异，体质越高生命力上限越高。
- 种族/体型修正用于巨人、怪物、英灵、病弱幼童等特殊身体。
- 生命力数值必须和前文 0-100 表现力标尺平衡：超凡角色生命池可远高于普通人，但不能让同级攻击完全失效。

| 当前值比例 | 表现 |
| --- | --- |
| 100% | 状态完整。 |
| 75%-99% | 轻微擦伤或不影响行动。 |
| 50%-74% | 明显受伤，行动受影响。 |
| 25%-49% | 重伤，持续行动困难。 |
| 1%-24% | 濒死或几乎失去行动能力。 |
| 0% | 死亡、昏迷或剧情判定失去生存能力。 |

### 精力

精力表示体能和持续行动余量。精力也是数值池，最大值与等级和体质挂钩。

```text
精力.max = round((等级 × 8) + (体质 × 5) + 职业/训练修正 + 特殊体质修正)
```

说明：

- 等级越高，持续行动和连续释放能力越强。
- 体质越高，精力上限越高，恢复和耐疲劳更好。
- 职业/训练修正用于运动员、士兵、魔术师、病弱者等差异。
- 精力 current 会因行动、战斗、施法、奔跑、饥饿、缺水、疲劳而下降。

| 当前值比例 | 表现 |
| --- | --- |
| 80%-100% | 行动顺畅。 |
| 50%-79% | 正常消耗。 |
| 25%-49% | 疲惫，爆发力下降。 |
| 1%-24% | 极度疲惫，难以持续行动。 |
| 0% | 无法主动行动或需要立即休息。 |

### 饱食度 / 水分

饱食度和水分主要服务生存体验，不与等级直接挂钩。

- 饱食度低会影响精力恢复、精神稳定与行动能力。
- 水分低会快速影响生命力、精力与判断。
- 职业和环境会影响消耗速度，例如士兵、矿工、运动员、荒野旅行者消耗更快。

### 疲劳度

疲劳度是负面累积值，越高越糟。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 清醒。 |
| 21-40 | 略有疲倦。 |
| 41-60 | 明显疲劳。 |
| 61-80 | 判断下降、行动迟缓。 |
| 81-100 | 接近崩溃，可能昏睡或失误。 |

### 学习能力

学习能力影响习得能力经验获取效率。

```text
学习经验倍率 = 0.5 + 学习能力 / 100
```

例：

- 学习能力 20：0.7 倍。
- 学习能力 50：1.0 倍。
- 学习能力 90：1.4 倍。

### 精神稳定

精神稳定有当前值和最大值。当前值短期波动，最大值代表心理韧性上限。

- 受恐惧、操控、创伤、压力、精神攻击影响下降。
- 受休息、安抚、熟悉环境、信任关系影响恢复。
- 意志高的人精神稳定最大值通常更高。

### 成长潜力

成长潜力影响非玩家长期成长，玩家不遵循该限制。

| 数值 | 表现 |
| --- | --- |
| 0-20 | 基本定型，成长空间很低。 |
| 21-40 | 仍可成长，但速度缓慢。 |
| 41-60 | 正常成长空间。 |
| 61-80 | 成长快速，适合年轻或天赋强角色。 |
| 81-100 | 天才、幼年关键角色、觉醒前角色。 |

等级越高，成长潜力通常越低。可以使用：

```text
有效成长潜力 = 成长潜力 × (1 - 等级 / 120)
```

## 等级与数值表现力总标尺

该标尺用于等级、力量、攻击输出、抗性、行动能力等可直接体现规模的属性。0-9 为普通人范围，10 以上为超凡范围。非破坏型属性需要转换成对应表现：智力对应处理复杂度与推演规模，感知对应感知范围与细节捕捉，意志对应精神抗性，魅力对应影响范围与支配感。

| 20 | 单纯力量能够压缩空气，破坏十几米长街道。 |
| 25 | 单纯力量能够破坏千人左右小镇。 |

| 35 | 能破坏十万人规模城镇。 |
| 40 | 能破坏百万人城市。 |
| 45 | 能破坏千万人大都市。 |
| 50 | 能破坏法国、日本这类面积的国家。 |

## 身内能力数值表现

身内能力不是把 1-100 平均切段解释，而是由“入库初始值”和“真实升级后累计成长”叠加出来。当前系统中每级的 2 点自动成长是 7 项身内能力合计获得 2 点，不是每项能力每级 +2；自由属性点也是每级合计 +1，只有玩家手动投入后才进入某一项。

```text
身内能力当前值 = 初始值 + 等级值 + 分配值 + 非玩家成长
真实升级次数 = level_growth.totalLevelUps
累计自动等级值 = 真实升级次数 × 2
累计自由点 = 真实升级次数 × 1
```

- 初始值：角色首次入库时，根据角色资料、当前年龄、所处世界、进入时间点和当前处境推演出来。现代普通人通常在 4-6，训练者或专业者可有 7-9；超凡角色必须有世界观依据。
- 等级值：真实升级时自动获得。系统按职业/身份、已有技能 `linkedStats`、当前短板和单项已高惩罚分配，每级只在全部身内能力中合计分配 2 点。
- 分配值：玩家消耗自由属性点手动投入。当前规则为每升 1 级获得 1 点自由属性点，初始等级不发放。
- 非玩家成长：非玩家角色在时间流逝、训练、学习、战斗、剧情压力中，由 AI 根据努力方向少量分配。

数值解释必须同时看“当前值”和“来源”。例如力量 8 可以是“初始 8 的训练者”，也可以是“初始 4 + 等级 2 + 分配 2 的成长者”。同样是 15，若来源为“初始 14 + 等级 1”代表天生/世界观强度，若来源为“初始 5 + 等级 6 + 分配 4”代表长期培养成果。

### 随等级变化参考表

下表按 `level_growth.totalLevelUps` 记录的真实升级次数计算。若角色初始就是 lv7 或 lv12，不会倒发自由点；只计算入库之后实际发生的升级。

| 真实升级次数 | 例：lv1 起步到达 | 累计自动点总量 | 累计自由点总量 | 单项平均自动成长 | 专精项常见自动成长 | 单项集中培养参考 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | lv1 | 0 | 0 | +0 | +0 | +0 |
| 1 | lv2 | 2 | 1 | +0-1 | +1-2 | +2-3 |
| 4 | lv5 | 8 | 4 | +1 左右 | +2-4 | +6-8 |
| 9 | lv10 | 18 | 9 | +2-3 | +5-8 | +14-17 |
| 19 | lv20 | 38 | 19 | +5-6 | +10-16 | +29-35 |
| 49 | lv50 | 98 | 49 | +14 左右 | +24-38 | +73-87 |
| 99 | lv100 | 198 | 99 | +28 左右 | +45-70 | 接近 100 上限 |

说明：

- 当前实现会把新角色初始等级直接写入 `level`，但 `level_growth.totalLevelUps` 仍为 0；因此 lv7 初始角色不是已经升过 6 次，而是入库时就处于 lv7。
- “单项平均自动成长”是把累计自动点平均摊到 7 项后的参考值，实际会受职业权重影响。
- “专精项常见自动成长”指战斗者的力量/敏捷/体质、学者的智力/感知/意志、领袖的魅力/意志/感知等被权重偏好的项目。
- “单项集中培养参考”是假设职业/技能权重长期偏向同一项，并且玩家把全部自由点也投入同一项；这是长期专精的上限参考，不是普通角色自然成长。
- 自动分配中存在 `values[key] / 50` 的高值惩罚和每次命中后权重衰减，因此单项不会稳定每级 +2；数值越高，越倾向被其他短板分流。

### 入库等级与初始值口径

| 入库角色类型 | 常见入库等级 | 初始身内能力口径 | 后续成长解释 |
| --- | --- | --- | --- |
| 幼童、病弱者、无训练者 | lv1 左右 | 多数 1-5，少数天赋项可到 6 | 后续成长空间大，但当前表现不能按未来潜力提前给高值。 |
| 现代普通学生/职员 | lv3-10，具体由资料与随机种子微调 | 多数 4-6，优势项 7，短板 1-3 | 升级后先补短板；达到 7-9 需要训练、经历或自由点投入。 |
| 训练者、军人、运动员、专业人士 | lv4-10，战斗/专业关键词会提高入库等级 | 相关项 7-9，非相关项仍可 4-6 | 10 以上需要超凡设定、长期升级或集中分配。 |
| 魔术师、骑士、医生、教师、学者等成熟职业 | lv7-10 左右 | 核心项 7-10，特殊世界观可到 12 | 成长应集中在职业相关三项，不应全属性同步暴涨。 |
| 英灵、从者、王、顶级高手、精英 | lv12-15 左右 | 核心项可 10-19，规格外需设定支撑 | 入库高值来自设定，不是从 lv1 自动补发的成长点。 |
| 神话、宇宙级、规格外存在 | 视设定而定 | 可突破普通人类口径，但必须绑定世界观强度 | 50 以上必须是设定或重大剧情突破，不能靠普通升级自然堆出。 |

### 按成长来源划分数值段

| 当前值段 | 常见来源组合 | 解释口径 |
| --- | --- | --- |
| 0 | 剧情损伤、封印、残疾、诅咒 | 不是正常生成值，只表示无法发挥。 |
| 1-3 | 低初始值，或严重短板 | 明显薄弱；普通人也可能在某些非擅长项落入此段。 |
| 4-6 | 初始普通值 | 现代普通人、一般学生、普通职员常见主体区间。 |
| 7-9 | 高初始值，或早期升级/训练补强 | 普通人优秀、训练者、专业者、人类自然上限附近。 |
| 10-12 | 高初始 + 少量成长，或普通初始 + 多次专精投入 | 初入超凡/准超凡；需要职业、训练、魔术、异能或长期培养解释。 |
| 13-15 | 高等级值/分配值开始明显累积 | 已明显脱离现实普通人；若无超凡设定，必须来自长线培养。 |
| 16-19 | 强设定初始值，或 lv20 左右长期专精培养 | 稳定超凡；普通现代身份不能直接生成到此段。 |
| 20-24 | 高规格设定，或大量升级 + 集中自由点 | 街区级表现；通常需要世界观能力或关键剧情突破。 |
| 25-34 | 长期高等级成长或高阶超凡初始 | 小镇到万人小镇级表现；应属于主力/高阶角色。 |
| 35-49 | 顶级超凡、神话/英灵规格或长线极限培养 | 城镇到大都市级表现；必须有明确设定支撑。 |
| 50-69 | 国家级到大陆/行星表层级设定 | 不能由普通训练自然得到，只能来自规格外存在或重大突破。 |
| 70-89 | 行星到宇宙级设定 | 极少数宇宙级角色。 |
| 90-100 | 单体宇宙到多元宇宙级设定 | 最高规格存在；普通升级只提供接近上限的机械空间，不代表可随意达到。 |

## 身内能力对其他属性的影响

| 身内能力 | 主要影响 | 表现力说明 |
| --- | --- | --- |
| 力量 | 攻击力、负重、近战伤害、破坏环境、压制动作 | 力量越高，徒手或重武器攻击力越高；10 以上进入超凡破坏。 |
| 敏捷 | 命中、闪避、先手、移动速度、行动能力、连击效率 | 敏捷越高，越容易减少受到的有效伤害，也更容易把攻击力转化为命中。 |
| 体质 | 生命力最大值、精力最大值、防御力、恢复力、抗病抗毒 | 体质越高，生命力与精力上限越高，受到同等攻击时生命力下降越少。 |
| 智力 | 学习能力、知识储备升级效率、复杂技能理解、战术推演 | 智力越高，学习知识/术式/复杂职业越快。 |
| 感知 | 精神稳定、侦察、危险预判、命中辅助、反偷袭 | 感知越高，越不容易被偷袭，也更容易发现弱点。 |
| 意志 | 精神稳定最大值、精神抗性、疼痛忍耐、专注施法 | 意志越高，精神稳定越不容易下降，濒死或受压时更能保持行动。 |
| 魅力 | 说服、威慑、领导、交涉、职业影响力 | 魅力越高，社会互动和统率型职业成长越快。 |

## 衍生能力：攻击力与防御力

攻击力和防御力是用于计算生命力增减的衍生能力，不是独立成长属性。

### 攻击力

攻击力主要由等级和力量决定，并受到敏捷、技能、武器、魔术、状态和战术影响。等级提供基础输出层级，力量提供主要破坏力差异。

```text
基础攻击力 = round((等级 × 4) + (力量 × 8))
最终攻击力 = 基础攻击力 + 攻击方式修正 + 技能修正 + 武器/魔术修正 + 情境修正
```

参考：

- 徒手攻击：主要看力量。
- 精密攻击：力量 + 敏捷 + 技能。
- 魔术攻击：魔力量/魔术回路/相关技能 + 智力或感知。
- 偷袭：攻击力不一定变高，但有效伤害上升。

### 防御力

防御力主要由等级和体质决定，并受到意志、护甲、防护术式、抗性、姿态和环境影响。等级提供基础抗性层级，体质提供主要肉体承伤差异。

```text
基础防御力 = round((等级 × 3) + (体质 × 8))
最终防御力 = 基础防御力 + 护甲/魔术防护 + 意志修正 + 情境修正
```

参考：

- 肉体承伤：主要看体质。
- 精神冲击：主要看意志，体质只作辅助。
- 毒、病、疲劳：主要看体质。
- 恐惧、操控、污染：主要看意志和精神稳定。

### 生命力增减

```text
有效伤害 = 最终攻击力 - 最终防御力 + 伤害倍率/克制/命中修正
若攻击被完全免疫：有效伤害 = 0
若攻击命中且未完全免疫：有效伤害 = max(1, 有效伤害)
生命力.current = max(0, 生命力.current - 有效伤害)
```

AI 判定时不需要机械暴露公式，但必须体现：

1. 高攻击力打低防御力，生命力明显下降。
2. 低攻击力打高防御力，可能只造成擦伤或无效。
3. 命中要害、偷袭、克制、状态异常会提高有效伤害。
4. 护甲、魔术防护、格挡、环境遮蔽会降低有效伤害。
5. 体质影响生命力最大值与防御力，力量影响攻击力。
6. 攻击力、防御力、生命力必须平衡：同级角色互相攻击应能造成有效消耗，但不应一击必杀；跨大等级攻击可以碾压。
7. 前文表现力标尺必须保留：50 级国家级角色的攻防与生命池都应远超 9 级普通人。

### 平衡示例

| 情况 | 预期结果 |
| --- | --- |
| 同级、攻防接近 | 每次命中消耗一部分生命力，需要多次有效攻击才能击败。 |
| 攻击力高于防御力 20% 左右 | 明显伤害，但通常不会满血秒杀。 |
| 攻击力高于防御力 100% 以上 | 可重创或秒杀，除非生命力极高或有特殊抗性。 |
| 防御力高于攻击力很多 | 擦伤、无效、被弹开，生命力下降极少或为 0。 |
| 等级差距跨越一个大层级 | 高层级角色可碾压低层级角色，符合表现力标尺。 |

## 习得能力等级与经验曲线

习得能力包括知识储备和技能。每项单独 lv1-lv7。

| 等级 | 描述 | nextExp |
| --- | --- | --- |
| lv1 | 入门，知道基本概念或能做最简单动作。 | 100 |
| lv2 | 初学，能在低压环境稳定使用。 | 250 |
| lv3 | 熟练，能处理常见情况。 | 600 |
| lv4 | 专业，能应对复杂情况。 | 1400 |
| lv5 | 专家，能创新或指导他人。 | 3200 |
| lv6 | 大师，领域内极少数高位者。 | 7200 |
| lv7 | 传说，世界观顶级或规格外。 | max |

### 等级元素初始生成要求

凡是带等级的元素，包括知识储备、技能、职业、世界专属能力或其它 lv1-lv7 条目，初次生成时必须同时生成当前等级说明与当前作用，避免只留下“名称 lv.2”而无法体现升级后的变强。

每个等级元素至少包含：

```text
name：名称
type：知识 / 技能 / 职业 / 世界专属能力
level：当前等级
levelDescription：该等级代表的掌握程度
effect：当前等级在剧情、判定或行动中的实际作用
exp：当前经验与升级所需经验
linkedStats：关联身内能力
source：来源或获得背景
```

生成规则：

- `levelDescription` 必须对应当前等级，不要写泛泛介绍。例如 lv1 是“知道概念/能做简单动作”，lv4 是“可独立处理复杂情况”，lv7 是“世界观顶级或规格外”。
- `effect` 必须写清该等级带来的实际增强，例如“战斗中更容易识破破绽”“能独立完成高中数学常见题型”“可承担正式医生职责”。
- 知识与技能只说明关联身内能力、经验、来源、等级说明和作用；不要显示关联习得能力或世界专属能力。
- 职业可以额外说明关联习得能力、世界专属能力、社会承认、职责范围和升级后职责/影响力变化。
- AI 生成职业/知识/技能资料时，必须围绕“升级后如何变强”写等级说明，而不是只写背景设定。

### 习得能力经验获取

```text
获得经验 = 基础经验 × 学习能力倍率 × 相关身内能力倍率 × 实践质量倍率 × 难度倍率
```

相关身内能力倍率：

```text
相关身内能力倍率 = 0.6 + 平均相关身内能力 / 100
```

实践质量倍率：

- 看书/听讲：0.5-0.8
- 普通练习：1.0
- 实战/高压实践：1.2-2.0
- 名师指导：1.2-1.8
- 生死突破：2.0-3.0，但可能带来伤害或精神损耗。

## 职业等级与经验曲线

职业等级范围 lv1-lv7。职业不是临时身份，而是角色能够长期承担的一套社会功能。

| 职业等级 | 表现 |
| --- | --- |
| lv1 | 见习或刚入门。 |
| lv2 | 能完成基础职责。 |
| lv3 | 独立从业。 |
| lv4 | 资深从业者。 |
| lv5 | 专家或核心成员。 |
| lv6 | 大师、权威或高阶职位。 |
| lv7 | 传说级、时代代表或组织顶点。 |

职业经验依赖：

1. 相关习得能力等级。
2. 相关身内能力。
3. 实际履职时间。
4. 成果质量。
5. 社会承认或组织认证。

职业失去规则：

- 失去阵营身份不等于失去职业能力。
- 长期失忆、身体失能、设定改变，才可能使职业等级下降或失效。
- 阵营地位变化只更新社会属性，不影响职业等级本身。

## 数值生成注意事项

1. 不要为了戏剧性把所有主角都设为高数值。
2. 幼年角色可以成长潜力高，但当前生命力、行动能力、力量通常较低。
3. 强大角色也可能精神稳定低、魅力低或学习能力一般。
4. 普通人的基础能力百分比可集中在 35-60；身内能力则通常集中在 4-6，训练者或专业者才进入 7-9，不能动辄 10+。
5. 超常数值必须有世界观依据，例如神秘强化、英灵、改造、怪物血统。
6. 外部身份、家族资源、组织地位应进入社会属性，不应提高身内能力。
7. 已掌握知识和技能应进入习得能力，不应混入智力或学习能力。
