# 角色能力结构 Schema

本文件用于作为 AI 生成人物能力资料时的提示词参考。AI 必须把角色能力拆分为：基础能力、身内能力、习得能力、社会属性。不同类别的含义、可变性、数值更新规则不同，不能混写。

## 总原则

1. 能力结构用于描述角色个人状态、成长、技能与社会位置，不等同官方设定。
2. 基础能力与身内能力是所有角色固有项，AI 不可删减字段。
3. 非玩家角色的身内能力不因单次剧情行动随意波动，只能在角色再次出现、长期成长、重大身体变化、受伤、诅咒、改造等情况下调整。
4. 习得能力与社会属性由 AI 根据角色经历、设定、当前剧情接触到的信息推断生成。
5. 外部资源、阵营地位、职业身份不能写入基础能力或身内能力。
6. 数值要体现现实可感的表现力：0-9 属于普通人范围，10 以上进入超凡层级，等级越高破坏规模、速度、抗性或影响范围越夸张。

## 基础能力（生存状态）

基础能力描述角色当前生存状态与成长状态。可量化，通常具有当前值与最大值。部分字段会随剧情即时波动。

| 字段 | 类型 | 说明 | 更新规则 |
| --- | --- | --- | --- |
| 等级 | number | 对角色综合评价，1-100 级。不是职业等级。 | 玩家可按升级体系成长；非玩家根据年龄、经历、成长潜力与再次出场间隔推断。 |
| 经验值 | object | 对角色成长曲线的描述。非玩家没有公式般升级方式。 | 玩家按经验曲线；非玩家以阶段性描述或估算值记录。 |
| 生命力 | current/max | 与体质有关，代表当前承伤、生存与身体完整状态。 | 受伤、治疗、疾病、恢复时变化。 |
| 精力 | current/max | 与体质有关，代表体能、耐力与持续行动余量。 | 行动、战斗、休息、睡眠时变化。 |
| 饱食度 | current/max | 与等级无关，受职业、身体消耗和环境影响。 | 进食、饥饿、长时间行动时变化。 |
| 水分 | current/max | 与等级无关，受职业、身体消耗和环境影响。 | 饮水、失血、炎热、运动时变化。 |
| 疲劳度 | current/max | 与等级无关，受职业、作息、压力和行动强度影响。 | 行动累积，上升；休息下降。 |
| 学习能力 | number | 与智力有关，表示理解、记忆、模仿与掌握新能力的效率。 | 通常不即时波动；长期成长、教育、脑部损伤等可改变。 |
| 精神稳定 | current/max | 与感知、意志、创伤和压力有关，代表心理稳定与判断能力。 | 恐惧、创伤、精神攻击、安抚、休息时变化。 |
| 成长潜力 | number | 影响未来角色出现时等级或能力增长速度。等级越高，成长潜力通常越低。 | 不影响玩家；非玩家长期成长时使用。 |
| 行动能力 | current/max | 与体质有关，代表移动、协调、反应与执行动作的当前可用能力。 | 受伤、束缚、疲劳、强化、残疾时变化。 |

### 基础能力输出要求

- 当前值/最大值字段使用 `{ "current": 数值, "max": 数值 }`。
- 等级范围为 1-100。
- 当前值不能超过最大值，不能低于 0。
- 疲劳度是负面状态，数值越高越疲劳。
- 成长潜力范围为 0-100；幼年、天赋强、训练空间大者更高；成熟强者更低。

## 身内能力

身内能力描述角色身体、心智、感官与人格底层资质。它们会成长，但不易波动，均与等级有关。所有角色固有，AI 不可删减，也不可因单次行动任意调整非玩家数值。

| 字段 | 说明 |
| --- | --- |
| 力量 | 肌肉强度、负重、近战伤害、爆发力。 |
| 敏捷 | 反应速度、灵活性、闪避、动作频率。 |
| 体质 | 抗病、恢复力、耐久、承伤、体能基础。 |
| 智力 | 学习能力、逻辑推理、记忆、理解复杂知识的能力。 |
| 感知 | 观察力、直觉、洞察、危险预感、感官敏锐度。 |
| 意志 | 抗压、专注、精神抵抗、坚持目标的能力。 |
| 魅力 | 说服力、亲和力、威慑、存在感与社会吸引力。 |

### 身内能力数值表现

身内能力用 0-100 表示，要求数值具有可感表现力：

| 数值段 | 表现 |
| --- | --- |
| 0-9 | 普通人范围：从虚弱、普通到训练有素的人类上限。 |
| 10-15 | 初入超凡：单手破坏钢铁且无副作用，或轻松破坏水泥墙壁且无副作用。 |
| 16-19 | 稳定超凡：能以身体能力压制现代武装个体，小范围破坏建筑结构。 |
| 20-24 | 街区级：单纯力量可压缩空气，破坏十几米长街道。 |
| 25-29 | 千人小镇级：单纯力量足以破坏约千人规模小镇。 |
| 30-34 | 万人小镇级：单纯力量足以破坏万人左右小镇。 |
| 35-39 | 十万人城镇级：可破坏十万人规模城镇。 |
| 40-44 | 百万人城市级：可破坏百万人规模城市。 |
| 45-49 | 千万人大都市级：可破坏千万人规模大都市。 |
| 50-59 | 国家级：可破坏法国、日本这类面积的国家。 |
| 60-69 | 大陆级到行星表层级。 |
| 70-79 | 行星级到恒星级。 |
| 80-89 | 星系级到宇宙级。 |
| 90-99 | 单体宇宙级到复数宇宙级。 |
| 100 | 多元宇宙级别。 |

该标尺主要用于等级、力量、攻击输出、抗性、行动能力等战力表现；智力、感知、意志、魅力等非直接破坏属性应转化为对应表现，例如计算规模、感知范围、精神抗性、支配影响范围。

## 衍生能力

衍生能力由基础能力与身内能力计算或推断，用于战斗/受伤/生命力增减判定。衍生能力不是独立天赋，AI 不应把它当成可单独成长的身内能力。

| 字段 | 主要来源 | 说明 | 用途 |
| --- | --- | --- | --- |
| 攻击力 | 力量为主，敏捷、技能、武器、魔术等修正 | 代表造成生命力下降的能力。徒手、武器、技能、魔术可产生不同攻击力。 | 计算目标生命力减少、破甲、压制或环境破坏。 |
| 防御力 | 体质为主，意志、护甲、抗性、魔术防护等修正 | 代表抵消生命力下降的能力。包括肉体耐久、抗冲击、恢复前缓冲。 | 抵消攻击力，降低生命力损失，判断是否受伤、重伤或无效。 |

### 生命力增减参考

```text
有效伤害 = max(0, 攻击力 - 防御力 + 情境修正)
生命力.current = max(0, 生命力.current - 有效伤害)
```

情境修正包括：武器克制、偷袭、命中要害、护甲、魔术防护、状态异常、疲劳、环境压制等。AI 只需要给出合理结果和理由，不必暴露完整公式。

## 习得能力（后天掌握）

习得能力是通过学习、实践、记忆、训练或经历积累出来的知识与技艺。它们与身内能力有关，身内能力高低影响学习效率与升级效率。

习得能力分为两类：

1. 知识储备：知道什么，例如历史、理论、情报、秘闻、规则理解。
2. 技能：会做什么，例如剑术、开锁、烹饪、说服、施法、潜行、急救。

### 习得能力规则

- 每个知识或技能单独拥有等级与经验值。
- 等级范围为 lv1-lv7。
- 每一项由哪些身内能力决定，由 AI 根据内容推断。
- 当前角色接触到什么知识或技能，也由 AI 根据剧情、职业、经历推断。
- 习得能力可以新增、升级、停滞或遗忘。
- 不允许把“阵营地位”“资源数量”“剧情制度影响”写成技能。

### 习得能力字段建议

```json
{
  "name": "剑术",
  "type": "技能",
  "level": 3,
  "exp": { "current": 120, "next": 300 },
  "linkedStats": ["敏捷", "力量", "感知"],
  "source": "长期训练与实战经验",
  "description": "能够稳定完成基础攻防，并在压力下使用常见剑技。"
}
```

## 社会属性（社会定位）

社会属性描述角色在社会结构中的位置，不等同个人基础能力。

### 职业

职业代表角色长期掌握并可持续运用的一套社会功能或专业身份，例如工程师、魔术师、医生、佣兵、教师。

规则：

1. 学生这类临时阶段身份通常不算职业，属于阵营/角色地位。
2. 职业一旦获得，除非长期遗忘、失能、设定变化，否则不会直接失去。
3. 单个角色可拥有多个职业。
4. 每个职业有独立等级与经验值，范围 lv1-lv7。
5. 职业由哪些身内能力与习得能力决定，由 AI 推断。
6. 若角色拥有职业但缺少对应习得能力，AI 应根据当前设定补足相关习得能力并开启升级体系。
7. 若未来再次出现，根据成长潜力、年龄、经历、职业活跃度推断职业增长或停滞。

### 阵营/角色地位

阵营/角色地位描述角色所属势力与在其中的层级或身份，例如：

- 第三人民医院 / 三级医生
- 第二中学 / 三年级中学生
- 魔术协会 / 见习魔术师
- 间桐家 / 被收养的孩子

规则：

1. 阵营/角色地位是社会位置，非永久性。
2. 不可升级，但可以变化、失去或新增。
3. 单个角色可拥有多个阵营/角色地位。
4. 不要把阵营/角色地位写进身内能力或基础能力。
