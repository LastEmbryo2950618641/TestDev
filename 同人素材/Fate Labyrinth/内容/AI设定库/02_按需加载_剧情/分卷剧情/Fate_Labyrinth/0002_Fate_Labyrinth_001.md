# Fate Labyrinth

﻿Fate Labyrinth
樱井光

Fate/Labyrinth Act-1


———沙条爱歌做了梦。



公历一九九一年，二月某日。
东京地下某处。
在谁也看不见的黑暗中，伸手无法碰触的底部。
有漂浮之物在此。有不断沉眠之物在此。有等待觉醒时刻之物在此。
其乃大圣杯(Saint Graph)。
累积人类意念之物，引导非此岸则来自彼方的「某种东西」之物。
正确来说虽也能称为仿造圣杯———
现在。这大圣杯正属某名少女所有。又或着说，重要地，被守护着。就象是只要掉到地上就会轻易破碎、脆弱的卵一般。
将伟大的圣杯，视为弱小的应庇护之物，爱歌持续守护着。
为了心爱之人的愿望。
时而碰触。对其出声。
也有闭上眼睛，编织有如摇篮曲般的旋律之时。
就像现在，这时一样。



———接着，短短地刹那间。



爱歌的意识动摇。
原本，不需要倚靠恢复肉体疲劳所需睡眠的根源皇女(Potnia Theron)，在那时确实感受到十分舒服的朦胧感。
那是不可能发生的事。
若不是特别去意识，这身躯应该是不需要休息的。
所以，这情况绝对不是偶然，也不是某种奇迹之类的事情。
而是在明确的意识下爱歌才得到睡眠。
理由只有一个。
为了做梦。
只是，突然间想到而已。像个"普通的人类"那样试试看吧。
意识立刻就离开肉体，朦胧之海的另一端，跨越世界尽头闪耀的光。



———然后，觉醒。



爱歌张开眼帘。
闪耀般绝艳的睫毛颤抖。
透亮的瞳孔于黑暗中也令人感到怜爱地散发光芒。
于现实与梦境的地平彼方。
在自己原本所处的世界，迥异的世界。
和自己原本所处的肉体，相异的肉体。
幻想种，合成兽(chimera)，无数致死的魔术陷阱蠢蠢欲动的≪迷宫≫中。



———就这样，邂逅。



就好像要守护变成无力存在自己的，一骑英灵(Servant)。
即使世界改变也仍然重逢，那样，命运中的对象。


「试问。你是我的御主吗」


明明应该是"同一个人"。
明明应该是不列颠王。
但那确实。
有着少女的外貌。

「哎呀———？」
歪头。
理由太过明白。
因为，在这里的确实是爱歌所知的骑士王，那份氛围，缠绕的清冽气息，隐藏救国愿望的碧蓝瞳孔，无论哪一个都是骑士王所有的———但却有非常明显的不同。
